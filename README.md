# Content-Factory

Контент-фабрика на Claude Code для двух независимых проектов:

- **Вернатун** — армянский разговорный клуб (строим первым);
- **Финград Консалтинг** — клон команды.

Мозг — подписка Claude Code. Код агентов/скиллов/правил — здесь, в git. Тяжёлые медиа-ассеты — во внешнем хранилище (в репозитории только ссылки).

## Навигация
- `ARCHITECTURE.md` — архитектура, слои, тумблер проектов, роли, стек.
- `PLAN.md` — пошаговый план разработки с чекбоксами и критериями прохождения фаз.
- `ACTIVE_PROJECT` — тумблер активного проекта (`vernatun` | `fingrad`).
- `shared/` — общее: скиллы, пайплайны, шаблоны, правила.
- `projects/<проект>/` — команда агентов, бренд, контент-план, черновики проекта.

## AI-видео

Первый тип нового модуля — [AI-комикс / ожившая иллюстрированная история](shared/pipelines/ai-video/README.md). Модуль `ai-comic-video` строит сценарный scene plan для вертикального ролика 9:16: 8–16 сцен, keyframe-промпты, motion-паттерны, safe zones и CTA. Тяжёлые изображения и видео остаются во внешнем хранилище.

## Старт

Разработка начинается с **Фазы 1 — Контент-директор (Вернатун)**. См. `PLAN.md`.

## Улучшение качества видео

Отдельный pipeline уже готового файла: [video-quality](shared/pipelines/video-quality/README.md).
