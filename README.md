# Content Factory

Монорепозиторий контент-фабрики: действующее веб-приложение Vernatun Content Factory, контентные проекты и общие материалы для будущих команд.

Разработка продолжается через Codex и Git. Claude Code и Cursor остаются поддерживаемыми адаптациями и историей проекта, но новые общие правила разработки начинаются в `AGENTS.md` и `веб/AGENTS.md`.

## Навигация
- `AGENTS.md` — общие правила работы Codex.
- `STATE.md` — актуальная передача контекста между сессиями.
- `веб/AGENTS.md` — правила разработки веб-продукта.
- `веб/DEV_PLAN.md` — активный план разработки приложения.
- `веб/ARCHITECTURE.md` — архитектура приложения и роли.
- Корневые `ARCHITECTURE.md` и `PLAN.md` — исходная концепция и план контентного контура; они не заменяют план приложения.
- `ACTIVE_PROJECT` — тумблер активного проекта (`vernatun` | `fingrad`).
- `shared/` — общее: скиллы, пайплайны, шаблоны, правила.
- `projects/<проект>/` — команда агентов, бренд, контент-план, черновики проекта.

## Продолжить разработку

1. Открой `STATE.md` и `веб/DEV_PLAN.md`.
2. Для задачи в приложении прочитай `веб/AGENTS.md` и релевантный аудит из `веб/docs/`.
3. Для карты инженерных ролей и навыков см. `веб/.agents/skills/content-factory-development/SKILL.md`.
4. Следуй циклу Клиент ↔ Оркестратор; не публикуй контент и не выкатывай production без явного одобрения.
