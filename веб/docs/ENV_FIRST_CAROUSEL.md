# Как подготовить первую генерацию карусели (ключи в `.env`)

Простая инструкция: куда вставить ключи, чтобы заработала генерация текста для каруселей и (по желанию) живая колонка «Конкуренты».  
**Никогда не вставляйте настоящие ключи в этот файл, в чат и в git.**

## 1. Откройте файл `.env`

1. Найдите папку проекта Content Factory (корень, рядом с `package.json`).
2. Откройте файл **`.env`** в любом текстовом редакторе (Блокнот, Cursor и т.п.).
3. Если файла нет — скопируйте `.env.example` и переименуйте копию в `.env`.

## 2. Ключ для LLM (обязательно для первой карусели)

В `.env` должна быть строка:

```env
AGGREGATOR_API_KEY=
```

После знака `=` вставьте ваш ключ от агрегатора **Polza** (без кавычек и пробелов).

Адрес API уже настроен для Polza — проверьте, что есть строка:

```env
AGGREGATOR_BASE_URL=https://polza.ai/api/v1
```

Подробнее про агрегатор: [`docs/ENV_AGGREGATOR.md`](./ENV_AGGREGATOR.md).

Без `AGGREGATOR_API_KEY` генерация текста идёт в упрощённом (mock) режиме.

## 3. Ключ для живых конкурентов (по желанию)

Чтобы колонка «Конкуренты» в Studio подтягивала реальные посты Instagram, добавьте:

```env
IG_SCRAPER_API_KEY=
```

После `=` — ваш ключ скрейпера (Apify). Опционально можно указать:

```env
IG_SCRAPER_BASE_URL=
```

Без этого ключа приложение не падает: показываются демо-данные / пустой список (soft-fail).

**S50:** если `IG_SCRAPER_API_KEY` задан, демо-фикстуры конкурентов **не** подмешиваются как «успех» (пустой список при сбое Apify). Чтобы снова включить фикстуры (CI/офлайн), добавьте:

```env
USE_FEED_FIXTURES=1
```

## 4. Отдельный ключ вендора каруселей (если появится)

Имена для будущего live-API каруселей описаны в [`docs/ENV_CAROUSEL.md`](./ENV_CAROUSEL.md) (`CAROUSEL_API_KEY`, `CAROUSEL_API_BASE_URL`).  
Для **первого** шага достаточно `AGGREGATOR_API_KEY` (текст через Polza).

## 5. Сохраните и перезапустите localhost

1. Сохраните `.env`.
2. Перезапустите локальный сервер приложения (`npm run dev` или как вы обычно запускаете).
3. Откройте Studio → модуль каруселей и проверьте генерацию.

Пока сервер не перезапущен, новые ключи из `.env` могут не подхватиться.

## Важно про безопасность

- Файл **`.env` нельзя коммитить** в git и нельзя присылать в чат.
- В документации и тикетах пишите только **имена** переменных, не значения ключей.
- Если ключ случайно попал в переписку — лучше сразу перевыпустить его у провайдера.
