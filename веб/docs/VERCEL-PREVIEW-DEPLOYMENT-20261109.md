# Тестовая Content Factory — состояние 9 ноября 2026

Код опубликован в отдельной ветке `codex/vercel-preview-20261109` репозитория Nighttech1/Content-Factory. Main и рабочий Selectel-сайт не менялись. Первый кодовый коммит201aa44 включает ранее проверенные исправления сборки, opt-in режим просмотра и мобильную навигацию.

## Проверено

- Два независимых сценария настоящих GET-обработчиков прошли с запретом сети, Prisma initialization и записи данных приложения. Данные явно тестовые: три черновика, доска, дизайн, существующая tracked эмблема. Рабочие черновики и настройки не копировались.
- Изменяющие и неизвестные API, генерация, загрузка, ingest и публикация отклоняются до обработчика. Аналитика обозначена mock, модель и cache-write не запускаются. Автоматическая миграция localStorage пропускается без очистки.
- Локальная Next15 production-сборка через `next build` (Webpack) завершена с typecheck и lint; прежние предупреждения остались, проверки не отключались. `vercel.json` задаёт тот же buildCommand.
- На localhost8088 браузер открыл Studio, меню и Settings, переход закрыл drawer. Это функциональная DOM/AX-проверка. Точный390px и визуальная приёмка не объявляются: Chrome был свёрнут, captureScreenshot завершался таймаутом; viewport override фактически оставил innerWidth520. Восстановление через опубликованные UI APIs не удалось. Нужна визуальная проверка после появления доступного окна/удалённого URL.

## Размещение пока не выполнено

Vercel в Chrome показывает гостевой импорт. Вход владельца ещё не завершён. Официальный CLI65.12.1 поддерживает anonymous temporary deploy, но сервер отклонил текущую попытку сообщением «Temporary deployments aren't available for this attempt. Log in to continue». Попытка остановлена; успешный deployment URL или claim link не получены. Обход ограничений сервиса не выполнялся.

Чтобы закончить публикацию, нужен вход владельца в Vercel и импорт именно отдельной preview-ветки:

- Repository: Nighttech1/Content-Factory; branch codex/vercel-preview-20261109.
- Root Directory: `веб` (кириллица).
- Framework: Next.js; Node22; buildCommand `next build` уже в конфигурации.
- Build и runtime: `CONTENT_FACTORY_PREVIEW=1`, `NEXT_PUBLIC_CONTENT_FACTORY_PREVIEW=1`.
- Не добавлять production .env, DATABASE_URL, провайдерские/социальные/Telegram-ключи, Redis и рабочие данные.
- Сохранить защиту доступа Vercel по умолчанию; изменение аудитории требует отдельного решения владельца. Production-домен существующего VPS сюда не переносить.

## Локальные технические особенности

Для проверки использованы существующие локальные зависимости Selectel-worktree через node_modules junction. SHA256 package-lock и Prisma schema совпадают; env/data junction отсутствуют. Локальный Turbopack отверг dependency junction вне filesystem root, поэтому проверена Webpack-сборка. Незавершённый cache npm ci перемещён вне исходного дерева; он не отслеживается и не отправлен в GitHub. Удаление рабочих данных не выполнялось.

Ветка подготовлена, но тикет остаётся открытым до реального Vercel URL и проверки на телефоне. Публикация production и функциональность генераторов/сохранений в этом режиме не заявляются.
