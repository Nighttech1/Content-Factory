# Инструкции для старых Claude Code-сессий

Канонические правила разработки этого продукта находятся в [`AGENTS.md`](./AGENTS.md). Они распространяются на все инструменты.

Claude-адаптации `.claude/` сохранены для совместимости. Реестр ролей: `.claude/registry/agents.md`; ролевые правила: `.claude/rules/`; инженерные навыки: `.claude/skills/`; продуктовые инструкции workers: `workers/<role>/SKILL.md`.

Следуй `DEV_PLAN.md`, сверяй статус с `docs/AUDIT_FUNCTIONALITY.md` и `docs/AUDIT_ARCHITECTURE_STACK.md`, а разработку веди по циклу Клиент ↔ Оркестратор из `docs/CLIENT_ORCHESTRATOR_CYCLE.md`. Не изображай невыполненные проверки и не выдумывай независимого участника приёмки.
