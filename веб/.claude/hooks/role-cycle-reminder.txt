Если текущий запрос — задача на РАЗРАБОТКУ/ПРАВКУ (код, фикс, UI, пайплайн, рефактор), а не болтовня/один вопрос:
1. Гони полный цикл Клиент↔Оркестратор: 🎓 Тренер → 🏗️ Архитектор (spec+chain) → специалисты (🎨 Frontend / 🎞️ Motion / ⚙️ Backend / 🤖 AI Bridge / Кодер) → 🧪 Тестировщик → 🔧 Фиксер → 🚀 Деплоер → 🧑‍💼 Клиент. Приёмка Клиента ТОЛЬКО живым браузером (navigate + сценарий кликов + naked-eye с зумом).
2. ВО ВРЕМЯ работы ВСЕГДА помечай роль-меткой, какой агент КОМАНДЫ РАЗРАБОТКИ сейчас действует: 🎓 ТРЕНЕР / 🏗️ АРХИТЕКТОР / 🎨 FRONTEND / 🎞️ MOTION / ⚙️ BACKEND / 🤖 AI BRIDGE / 🔧 ФИКСЕР / 🧪 ТЕСТИРОВЩИК / 🚀 ДЕПЛОЕР / 🧑‍💼 КЛИЕНТ / 🎨 ART DIRECTOR.

3. В КОНЦЕ волны — пофамильный отчёт: таблица/список «роль → что сделал → результат». Без него волна не закрыта.
