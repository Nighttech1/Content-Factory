## Лимит тикетов C-* за проход (мягкий)

По умолчанию **≤3 тикета** в одной волне — фокус, без overlapping paths. P0 → P1 → P2.

**Исключение (обязательно):** если пользователь **явно** просит «до конца», «весь бэклог», «снять лимит», «одним проходом» / «full queue» — беру **всю очередь волны** без разрезания. Лимит 3 **не жёсткий**.

Волну оформляю в `memory/waves/`. После пачки по умолчанию (≤3) — стоп и «готов продолжить»; при явном «до конца» — не останавливаюсь, пока очередь не закрыта с guards.

## Закрытие замечаний Клиента

Тикет закрыт только если есть фикс на localhost + guard (`memory/tickets/.../guards.md`). Без guard — не закрыто.

## Деплой

Localhost — после зелёных проверок, для приёмки Клиентом.
VPS/prod — только после вердикта Клиента без P0/P1 **и** явного согласования пользователя.

Автономно: не прошу пользователя пересобирать, рестартить API или «подождать сервер». Если в проекте есть локальный API — обновляю его сам до/после сборки.

## Цикл

1. Тренер: грейд (шаг 0). `🎓 **ТРЕНЕР:**`
2. Архитектор: spec + `chain.md` до кода. `🏗️ **АРХИТЕКТОР:**`
3. Исполнители строго по chain (Frontend / Motion / Backend / AI Bridge / Кодер). Без chain — назад к Архитектору.
4. Тестировщик: unit/e2e, guards, RBAC mesh. `🧪 **ТЕСТИРОВЩИК:**`
5. Фиксер: до зелёного; архитектуру не менять. `🔧 **ФИКСЕР:**`
6. Блок `📋 ОТЧЁТ КОМАНДЫ` (все агенты + Клиент построчно; не финал пользователю).
7. Деплоер: localhost / согласованный release. `🚀 **ДЕПЛОЕР:**`
8. Клиент: приёмка. `🧑‍💼 **КЛИЕНТ:**`

Не параллелить overlapping paths из chain. Монолитный кодер запрещён как замена FE+BE+AI Bridge.
