# Breakpoints — premium mobile

Канон для лендингов команды (согласован с `taste-skill`):

| Token | Min width | Назначение |
|-------|-----------|------------|
| base | 0 | телефоны, одна колонка |
| sm | 640 | крупные телефоны / small landscape |
| md | 768 | планшет, 2 колонки где уместно |
| lg | 1024 | лёгкий десктоп |
| xl | 1280 | полный десктоп |
| 2xl | 1536 | ultrawide — не обязателен для приёмки |

## Приёмочные устройства (эмуляция MCP)

| Label | Device preset | Approx CSS | Роль |
|-------|---------------|------------|------|
| iPhone | `iPhone 15` | ~393×852 | обязательный |
| Android | `Pixel 7` | ~412×915 | обязательный |
| Compact | resize 375×667 | 375 | регресс мелких |
| Tablet | resize 768×1024 | 768 | по ТЗ |
| Desktop | 1440×900 | 1440 | уже в `playwright` |

## Чеклист на каждом breakpoint

1. Нет `overflow-x` у document
2. Nav / burger работает пальцем
3. Hero CTA в первом экране или один короткий скролл
4. Карточки/гриды → 1 col на base
5. Шрифты читаемы (≥16px body)
6. Интерактивные скролл-сцены не «залипают» (см. `mobile-touch-scroll`)
