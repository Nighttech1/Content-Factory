# Материалы и сетка

## Сетка

- База **8px**. Исключения — 4px для hairline-зон.
- Контентная ширина люкса чаще 1120–1320, не «container max-w-7xl + 12 колонок карточек».
- Вертикальный ритм крупный: 80 / 120 / 160, не `py-8` везде.

## Поверхности

| Слой | Когда |
|------|--------|
| Бумага | Основной фон, статьи, кейсы |
| Hairline | 1px `rgba(…, 0.08–0.14)`, не 1px solid gray |
| Стекло | Один раз на overlay, не на каждую карточку |
| Металл/лак | CTA, логотип, ключевой объект |

## Тип

- Display + text. Не три гротеска.
- Заголовок: плотный leading 0.9–1.05, не 1.4.
- Цифры в таблицах — tabular nums.
- На тёмном фоне не чистый белый `#FFF` для длинного текста — чуть тёплый/холодный off-white.

## Свет

Один ключевой свет. Запрещены два конкурирующих неона. Тени мягкие и направленные, не «все карточки парят».
