## 4. Сетка карусели (4:5 — 1080×1350)

| Параметр | Значение |
|----------|----------|
| Canvas | `1080 × 1350` |
| Safe margin (все стороны) | `__ px` |
| Колонки / треки | одна колонка / фиксированный layout id: `____` |
| Вертикальный ритм (gap) | `__ px` |
| Радиус скруглений | `__ px` (или `0`) |
| Тень | запрещена / разрешена (описание) |
| Нумерация слайдов | позиция + стиль (напр. `01/08` top-right) |
| Логотип | позиция + max-width + opacity |
| Footer / CTA bar | высота + текст-шаблон |

**Layout system id** (обязательно): `carousel-v1` / другое имя.  
Все слайды одной джобы используют **один и тот же** layout id. Новый layout = новая версия в brandbook, не «на глаз».

### Разрешённые типы слайдов (только из списка)

- [ ] `cover` — обложка (бренд + хук)
- [ ] `point` — один тезис + короткий body
- [ ] `list` — 3–5 пунктов, одинаковые маркеры
- [ ] `quote` — цитата + атрибуция
- [ ] `compare` — две колонки A/B
- [ ] `cta` — финальный призыв + handle

Другие типы слайдов **запрещены**, пока не добавлены в этот чеклист.
