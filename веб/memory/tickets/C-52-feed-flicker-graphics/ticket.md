### [C-52] Моргание конкурентов + карточки инфографики
- **Зона / Экран:** `/studio/[moduleId]` dual feed, особенно «их» колонка; `/studio/aesthetic-graphics`
- **Факт:** Правая колонка постоянно моргает: при `competitorsLoading` сетка заменяется pulse-скелетонами. В полезных картинках на статичных изображениях круглая кнопка Play; нет репостов/комментариев.
- **Ожидание:**
  1. Карточки конкурентов не мигают при поиске/рефетче; скелетоны только при первой пустой загрузке.
  2. В aesthetic-graphics нет Play; видны комментарии и репосты.
- **Приоритет:** P0
- **Зона:** Frontend (+ Motion если pulse остаётся)
