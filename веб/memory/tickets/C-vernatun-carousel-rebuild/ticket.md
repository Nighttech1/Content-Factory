# C-vernatun-carousel-rebuild

**Приоритет:** P0  
**Модуль:** carousel-engine  
**Источник:** ТЗ Vernatun Carousel Agent v1 + PNG v5 + ответы Клиента 2026-10-21

## Цель

Полностью снести старый пайплайн карусели (layered_html / correct / e2e / anchor_ref) и заменить модулем Vernatun с режимами A (HTML/CSS) и B (AI-слайд), оркестрацией агентов, QA и repair loop.

## Приёмка (Клиент)

1. В «Создать карусель» есть переключатель «Режим сборки» A/B; выбор пишется в журнал задания.
2. Сценарист сначала присылает сценарий в чат на согласование; без «Одобрить» сборка не стартует.
3. Цвета из активного DESIGN.md / preset; композиция — Vernatun-эталон + арт-директор.
4. Черновики сохраняют результат; справа сверху — кнопка удаления (мусорка).
5. После ≤3 repair при BLOCKER — PNG отдаются, в чате явно «есть замечания», статус не FINAL.
6. Модели ролей конфигурируемы (role→provider→model), не зашиты.
7. Пусконаладка: 4 карусели × 4 слайда на localhost.
8. Режим A визуально близок к PNG v5 (бренд-зона, счётчик, панели, без keyword-salad).
