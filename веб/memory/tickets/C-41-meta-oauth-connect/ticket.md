## Expected (языком приёмки)

1. Есть экран/мастер «Подключить Instagram клуба», где человек **не вводит пароль Facebook в нашу форму**.
2. По кнопке открывается официальное окно Meta → друг входит своим аккаунтом клуба → разрешает доступ.
3. После успеха на экране видны (маскированно): **Page ID**, **IG User ID**, статус «токен получен»; фабрика может писать их в локальный конфиг / `.env` (без показа полного токена).
4. Кнопка «Проверить связь» дергает Graph API и показывает live/ошибку (как badge «Онлайн · Instagram» в Studio).
5. Без настроенного Meta App — понятная инструкция «что сделать в кабинете Meta», а не 500.

## Notes

- Фабрика уже ждёт env: `IG_ACCESS_TOKEN` (или алиасы) + `IG_USER_ID` (см. C-36…C-40).
- Цель волны — **получить** эти значения через UI, а не продолжать вставлять руками из Graph Explorer.
