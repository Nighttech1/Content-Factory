- [scriptwriter] 1. Переписать cover-caption с 3 вариантами hook'а (≤10 слов каждый), убрав служебные теги ('AUDIT-FIX B', 'clean poster'). Вариант A: вопрос ('Когда молчание говорит громче?'). Вариант B: противоречие ('Тишина, которая кричит'). Вариант C: обещание ('3 типа молчания, которые меняют всё'). Критерий: каждый вариант содержит curiosity-gap или value-promise, видим на превью без свайпа.
- [scriptwriter] 2. Добавить микротекст на слайды 2–4 (1–2 строки per slide) с логикой прогрессии: Слайд 2 (город) — 'Молчание в суете' или 'Тишина среди шума'. Слайд 3 (лес) — 'Молчание в природе' или 'Когда слова не нужны'. Слайд 4 — финальный вывод ('Молчание в себе' или резюме). Критерий: каждый текст = ответ на cover-question, не просто описание. Tone: философский, спокойный.
- [scriptwriter] 3. Добавить явный CTA на слайд 4, выбрав из Vernatun Catalog: CTA#1 (вопрос) — 'Какой тип молчания резонирует с тобой? Напиши 1, 2 или 3'. CTA#2 (ещё) — 'Ещё 5 типов молчания в следующей карусели — подпишись'. CTA#3 (клуб/TG) — 'Обсудим в нашем чате [ссылка]'. Критерий: CTA конкретный, не абстрактный ('напиши комментарий' → 'напиши цифру').
- [designer] 1. Добавить visual hierarchy на cover (слайд 1): разместить cover-caption поверх изображения в safe-zone (верх или низ) с контрастным фоном или shadow. Использовать контрастный текст (белый или чёрный) с читаемостью ≥14pt на мобильном. Убрать служебный текст, оставить только hook-фразу (≤8 слов). Критерий: caption видна на превью (0–2 сек), не требует свайпа.
- [designer] 2. Создать visual motif для слайдов 2–4 (микроэлементы для связности): Вариант A — добавить одинаковый фильтр/оверлей (лёгкий blur или colour-grade) на все слайды. Вариант B — добавить иконку/символ (ухо, волна, точка) в один угол каждого слайда (одинаковый для всех). Вариант C — добавить номер слайда (1/3, 2/3, 3/3) в consistent позиции. Критерий: юзер понимает, что это серия, а не случайный набор фото.
- [designer] 3. Проверить contrast и readability для текста на слайдах 2–4: если текст белый — добавить полупрозрачный чёрный фон (overlay) за ним. Если текст чёрный — добавить белый outline или shadow. Тестировать на мобильном (720×1200) в режиме preview. Критерий: текст читаемый на любом фоне (светлые горы, тёмный лес, город).
