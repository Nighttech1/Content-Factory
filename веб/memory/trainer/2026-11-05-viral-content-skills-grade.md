# Trainer readiness: Viral content skills

- Дата: 2026-11-05
- Запрос: подготовить роли директора, скаута, рилсов и каруселей к качественным и потенциально вирусным материалам; отдельно гарантировать красивые motion-вставки в рилсах.
- Грейд: **B** — основная структура отделов, brand-kit, референсы и рендеринг уже описаны; недостаёт явно применяемых методик анализа вирусности, проверки источников и motion-дизайна.

## Проверенные исходные условия

- Пайплайн рилсов уже называет Remotion для титров и анимаций, но не требует motion-brief и критериев QA для каждой единицы.
- FFmpeg и локальный `reel-ffmpeg` скилл существуют; базовый экспорт не равен полноценному motion-дизайну.
- Карусельный пайплайн имеет арт-директора, HTML-бейк и пять визуальных типов; нужно дать арт-директору систематику структуры/удержания без обещаний охватов.
- Директор должен опираться на KPI встреч клуба и не превращать внешние тренды в копирование.
- Скаут уже требует ссылок и дат, но нуждается в явном качестве доказательств, контексте выборки и запрете считать вирусный пример гарантией результата.

## Решение по внешним материалам

Проверены поисковые результаты GitHub по Reels/видео и каруселям. Самые зрелые найденные видео-инструменты — `calesthio/OpenMontage` и `kajisho5/ffmpeg-skill`; карусельные материалы `EricTechPro/instagram-carousel-skills` и `ishort-pro/instagram-claude-skills` имеют низкую популярность/мало звёзд. Репозитории используются только как идеи для внутренних процедур; чужой исполняемый код и сторонние зависимости не копируются.

Hugging Face поиск не выявил подходящего переносимого skill/plugin для наших контент-чатов; модели видеомонтажа на HF не являются MCP-подключениями. Подключаемых plugin/MCP-инструментов для этого в текущем чате не обнаружено.

## Дефициты для архитектора

1. Развести стратегию директора, доказательность скаута, сценарное ремесло каруселей и motion-производство рилсов.
2. Добавить пилотные skills с процедурами, входами, выходами и QA.
3. Создать короткие стартовые prompts начальников отделов.
4. Добавить motion brief + этапы дизайн → рендер → просмотр → исправление, используя Remotion при доступности и FFmpeg как финальный сборщик.
