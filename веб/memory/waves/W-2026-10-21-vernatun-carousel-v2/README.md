# Vernatun Carousel Agent — TZ v2

Состав пакета:
- `TECHNICAL_SPEC_CAROUSEL_AGENT_v2.md` — полное ТЗ.
- `PROMPT_PACK_v2.md` — краткая карта ролей и промтов.

Ключевое изменение относительно предыдущей версии: главный арт-директор на этапе 5 имеет право самостоятельно выбирать размеры, положение и стиль блоков, включая нумерацию слайдов. Глобальные размеры не должны навязывать композицию. Арт-директор обязан выдавать конкретные замечания и проверять исправления.
