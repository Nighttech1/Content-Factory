# Chain — Reels department runner

1. **Trainer** — audited readiness and reinforced the missing persistent rules.
2. **Architect** — defined the two-mode intake, phase contracts, gates, blockers,
   and truthfulness constraints before edits.
3. **Content-pipeline specialist / profile author** — implemented the lead-runner
   skill, specialist masks, and updated department entry points and roster.
4. **Tester** — run documentation consistency, link, checklist, and whitespace
   checks; correct any contradictions found.
5. **Fixer** — only if Tester finds a defect; patch and repeat targeted checks.
6. **Deployer** — N/A: no runnable service or web application changed.
7. **Client** — review the implemented docs and report factual scope/limitations.

No independent subagents were spawned for this repository change; roles in this
chain are review stages performed by the primary working agent. This is distinct
from the named product role-masks defined for future Reels production.
