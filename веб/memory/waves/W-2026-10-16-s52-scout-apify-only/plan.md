# W-2026-10-16-s52 — Scout-only Apify

## Цель (простым языком)

Скрапер Apify тратит деньги каждый раз, когда его вызывают. Раньше он мог срабатывать при **открытии** экрана «Конкуренты». Теперь:

1. **Конкуренты** только **показывают** последний результат Скаута (снимок). Открытие экрана = **0** вызовов Apify.
2. Скаут в «Команде выпуска» получает кнопку **«Разведать»** и блок настроек авторазведки (фильтры + частота).
3. Apify вызывается **только** по кнопке или по расписанию авторазведки.
