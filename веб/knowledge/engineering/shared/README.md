# Shared — инженерия

- **Стек не фиксирован.** Его задаёт Архитектор в `architect-spec.md` текущего проекта.
- **Skill-first:** сначала `SKILL.md` роли, потом эта KB.
- **Два контура:** инженеры пишут и проверяют; Клиент принимает.
- **Лимит:** по умолчанию ≤3 тикета `C-*` за проход; при явном «до конца» — вся очередь волны.
- **Данные священны:** не затирать пользовательские хранилища; MCP к БД — только read-only.
- **Закрытие тикета:** фикс + guard. Разовый патч без предохранителя = не закрыто.
