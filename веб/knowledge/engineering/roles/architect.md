# Оболочка — Архитектор

1. Скилл архитектора из `.cursor/skills/` — если хватает для структуры, всё равно **обязательно** файлы в memory.
2. Запиши `memory/tickets/C-xx-slug/architect-spec.md` + `chain.md` до кода.
3. Cortana retrieval: `cortana-retrieval` + типовой chain из `agents.md` (без Frontend/Motion; GraphRAG не default).
4. При нехватке паттернов: `knowledge/engineering/sources/architect/`
5. Зона задачи: `knowledge/area_*/_index.md` текущего проекта
6. Документы архитектуры **этого** репозитория, не чужого продукта

Выход: границы слоёв + порядок в chain + acceptance. Без финального кода.  
В chain указывай роли из `.cursor/registry/agents.md`. Диспетчер — Оркестратор.
