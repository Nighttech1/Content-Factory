**Клиент платит за смысл + словарь, не за «красивую воду».**

---

## MAKE — виральный сценарий speaking-club

### Хук и драматургия
1. **Обложка = стоп-скролл ПРО ТЕМУ** (≤4 слова RU). Не мотиватор «Начни сейчас». Body обложки обязателен: боль / обещание / о чём серия.
2. **Один слайд — одна мысль.** Mid = конкретный совет/факт/шаг, который можно применить сегодня.
3. **Серия:** hook → польза → CTA из брифа.
4. **Swipe-логика:** конец mid намекает «листай дальше», без кликбейта-лжи.
5. **central_thesis** = одна ясная мысль на всю карусель.

### ПОЛЕЗНОСТЬ И ПРАКТИКА (HARD — анти-болото)
6. **Критерий слайда:** после чтения человек знает **что сделать за 10 минут** — шаг, ссылка-ориентир, чек-лист.  
7. Каждый mid содержит ≥1 **именнованный ориентир**: сайт, канал, тип площадки, поисковый запрос, документ, действие.  
   Примеры: LinkedIn, Remote OK, Staff.am, Telegram IT Ереван, coworking-митап, gov/учётный кабинет — **не выдумывай секретные базы**.  
8. **Юр.статус / ИП / налоги — уместны**, если дают практическую пользу в контексте темы (например «как принимать оплату remote»). Тогда: конкретный следующий шаг + hedge («уточните у бухгалтера / на актуальном gov-сайте»).  
   Нехорошо: вся серия = общие фразы про ИП без площадок поиска, когда бриф про *поиск вакансий*.  
   Хорошо: один слайд про статус **рядом** со слайдами про площадки/резюме/комьюнити — баланс пользы.  
9. Не выдумывай законы, ставки, гарантии. Спорное → «проверьте актуальность».

### Словарь (HARD)
10. На каждом слайде `supporting_copy` = ровно одно HY—RU (`Հայերեն — русский`).  
11. Слово по тезису слайда; RU-смысл в body/headline. Headline/body/cta без HY.  
12. Слова разные по слайдам.

### Форма / атмосфера (HARD — mid живые как обложка)
13. **Каждый слайд** `image_need.kind=photo_generic` (или photo_real_place). **Запрет `kind=none`** — он рождает мёртвый чёрный UI без фото.  
14. **Списки в body** — только когда тема реально требует перечисления шагов/площадок; не превращай каждый mid в checklist.  
15. **FACT_CHECK:** если в брифе FACT_CHECK / research lock — не выдумывай цифры вне VERIFIED safe_wording.  
14. `visual_intent` = живая сцена (кафе/коворкинг/стол/город), не «графичный чистый слайд».  
15. `composition_hint` для mid: `photoreal full-bleed + list cards/checklist OVERLAY on-photo + vocab chip = series lock filled pill`.  
16. Обложка = poster-typo on-photo; mid = списки **поверх** фото, не вместо фото.  
17. `type_system` один; финал = CTA из брифа.

### Анти-паттерны
- Вода без шагов/имён  
- Mid `kind=none` / «тёмный интерфейс без сцены»  
- Mid, после которого неясно «что открыть»  
- Словарь не по теме  
- Кавычки-обёртки вокруг headline
