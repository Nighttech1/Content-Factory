# Frontend — Content Factory

Применяй вместе с `веб/AGENTS.md`. Перед изменением прочитай `.claude/rules/frontend.md` и только релевантные доменные навыки (`content-factory-ui`, `design-system`, `responsive-mobile-web`, `web-motion-engine`).

## Порядок

1. Найди существующий экран, компонент, состояние и владельца API; прочитай актуальный UI-контракт в skills и тикете.
2. Сохрани утверждённую оболочку и привычную модель взаимодействия. Новые UI-паттерны вводи только для запрошенной функции.
3. Используй существующие токены/компоненты. Не вводи параллельные цвета, радиусы, шрифты или отступы.
4. Для данных отличай loading, empty, error и success. Не показывай успешное завершение для mock или ошибки интеграции.
5. Проверь локально изменённые состояния только если пользователь запросил проверку; не запускай тесты самовольно.

## Готовый результат

Изменение ограничено нужным сценарием, не меняет принятые экраны и API-контракты без причины, а непроверенные состояния явно названы в отчёте.
