# Порядок выполнения

Тренер: B для пакета, D для production: транспорт VPS и код бота не подтверждены.
Архитектор: контракт и критерии до кода.
Кодер: стандартный Python CLI и workflow, без UI и продуктовых API.
Тестировщик: офлайн проверки гейтов и запроса/receipt, без внешних отправок.
Клиент: проверка фактического diff, прозрачный статус частичной готовности.
Frontend/Motion/AI Bridge пропущены: UI и вызовы LLM не изменяются.
Деплоер production пропущен по внешнему блокеру; фиктивной приёмки нет.
Роли выполняет один исполнитель последовательно, независимых субагентов нет.
