# Пакет SEO-сценариста и отправитель статей

До реализации зафиксированы границы: новый выход articles/*.json связан с jobs,
редакционные гейты сохраняются, GitHub отправляет только approved и due версии.
VPS является владельцем рендера, синхронизации дашборда и outbox действующего бота.
Детерминированный CLI не вызывает LLM, не меняет интерфейс, БД и nginx.
Критерии: draft/future не отправляются, правка content отменяет прежнее SHA-одобрение,
повторы распознаются по ключу, ответ сервера сверяется по id/revision/hash.
Сквозной выпуск блокируется отсутствием подтверждённого endpoint и исходников бота.
