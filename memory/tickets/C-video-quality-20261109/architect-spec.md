# Улучшение качества видео — спецификация до кода

2026-11-09; before_sha: e5bd3e1bd4ce1d34c9dd8139b6eb86a0e70a0701.

## Задача и границы

Отдельный исполняемый pipeline для существующего видео, независимо от создания
рилсов. Git хранит только код, шаблоны и текстовую память. Тяжёлые файлы — вне Git.
Не менять веб, БД, месячный план, генераторы роликов или существующие workflows.
Никаких paid API, GPU runners GitHub, расписаний, публикации и production deploy.
Ручной запуск; source URL только из Secrets, не из публичного workflow input.

## Контракт

- Intake: отдельный технический quality ID VQ-YYYYMM-NN; родительский REL ID
  при наличии сохраняется отдельно и никогда не переименовывается.
- check/selftest без пользовательского видео; diagnose — метаданные, полное
  декодирование, 5 кадров; sample — два синхронных MP4 и comparison на 3–5 с.
- CPU profiles: baseline / gentle / denoise / lanczos; это не нейросетевой апскейл.
- final требует принятой sample manifest, того же SHA256 исходника и настроек.
- Автопроверки: декодирование, размеры, SAR, rotation, длительность, fps, звук;
  они не означают визуальное улучшение. Финальный статус NEEDS_VISUAL_REVIEW.
- HDR и сложные/переменные тайминги для GPU — явный стоп, не тихая конверсия.
- GPU notebook Kaggle/Colab: CUDA check → upload → official RealESRGAN x2
  trial с tiled inference → сравнение → ручное принятие → full. Без face restoration,
  интерполяции, обучения, платного billing и API-сервера. GPU runtime не гарантирован.
- Оригиналы не перезаписываются. Новый непустой output каталог для каждого запуска.
- CPU workflow защищает права и передачу: rights_confirmed, allowlisted HTTPS
  source, размер ≤500 MB, длительность ≤180 s; экспорт artifacts 3 дня.

## Приёмка

Синтетический клип: diagnose → sample → отказ final без принятой пробы → final
после принятия → весь файл декодируется, звук/длительность/размеры сохранены.
Отрицательные проверки: чужой source hash, другой профиль, права, HDR, path
collision, сетевой allowlist, нулевой/некорректный диапазон. Notebook code cells
компилируются; CUDA обработка остаётся непроверенной без реального GPU.
Фото/аудио/права человека не выводятся из загрузки файла. Диагностика присланного
файла разрешена текущим запросом, финальная выдача требует подтверждения прав.

## Ограничения среды

FFmpeg/FFprobe 7.1.5 доступны. GPU не подтверждён. GitHub-коннектор не имеет
инструмента workflow_dispatch; свежий удалённый run нельзя обещать. Если запись
workflow запрещена permissions приложения, запушить остальной пакет и вернуть
точную ручную инструкцию. UI/browser QA неприменим: новый веб-интерфейс не создаём.
