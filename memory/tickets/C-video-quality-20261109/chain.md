# Chain

Все роли выполняются последовательно одним ассистентом. Субагенты запрещены.

1. Клиент: три тикета — диагностика, исполняемый pipeline, GitHub/GPU handoff.
2. Тренер: B по CPU, C по GPU; закрыть разрыв runtime честным capability check.
3. Архитектор: эта spec и chain до кода; path lock shared/pipelines/video-quality/.
4. AI Bridge: контракт бесплатного notebook, official model, явный CUDA gate.
5. Кодер: Python CLI/защита загрузки/Actions/manual templates, без веба и БД.
6. Тестировщик: синтетический end-to-end и negative gates, notebook syntax.
7. Фиксер: исправить конкретные падения и повторить затронутые проверки.
8. Деплоер: локальный CLI запуск (localhost/UI SKIP), push по поручению владельца.
9. Клиент: доказательства, ограничения, что требуется с телефона; приёмка владельца
   остаётся открытой до его слова «согласовано».

Frontend/Motion/Art Director/Backend пропущены: UI, новые анимации, брендинг,
серверный API, БД и очереди в данной волне не создаются. Роли производства видео
не запускаются, сценарий/монтаж/текст ролика не меняются.
