# Источники трендов для ручной разведки Скаута

Проверено 10.11.2026, Москва. Инженерная проверка публичных страниц и официальной документации, не запуск сборщика и не готовый список тем. Не создавались аккаунты, не вводились ключи и не запускались платные API, Actions-коллекторы или автоматический scraping. Возможность прочитать описание сервиса не означает, что из текущего чата доступен весь его каталог.

**Рекомендуемый старт без расходов:** публичная проверка Spytrend и доступных первоисточников; Google Trends — для контекста интереса; TikTok Creative Center — при фактически доступном UI/аккаунте. TOPREELS сейчас только с явной меткой исторических данных. Перечень — рекомендация по способу работы, не гарантия доступности или релевантности каждому запросу.

Опционально существующий транспорт YouTube можно использовать позднее по разрешённому заданию: [официальный videos.list](https://developers.google.com/youtube/data/reference/rest/v3/videos/list) возвращает видео по ID либо `mostPopular` для региона/категории и имеет квотную стоимость. Ключ/квота/валидный ответ в этой проверке не испытывались; прошлый неудачный run не повторять автоматически.

## Как фиксировать находку

У каждой находки отдельная запись доказательств:

- `discoveredVia`: агрегатор, URL страницы/фильтра, выбранные регион, период и сортировка.
- `primaryUrl`: прямая публичная ссылка на сам Reel/Short/статью. Не ссылка на сервис вместо первоисточника.
- `platform`, `author`, `publishedAt`: фактически видимые сведения; неизвестное — `null` плюс причина.
- `observedAt`: дата/время проверки с timezone; отдельно `providerUpdatedAt`, если сервис указывает свежесть своей базы.
- `metrics[]`: название, value либо `null`, единица, exact/bucketed/vendor estimate, период, URL источника, дата проверки. Агрегаторскую оценку не выдавать за измерение платформы.
- `viralityBasis`: что именно позволяет говорить о росте — например, vendor multiplier и его формула/окно. При отсутствии базы — «популярность не подтверждена», а не придуманный score.
- `access`: primary opened / login required / unavailable / only aggregator visible. В данной проверке переход на пример Instagram из TOPREELS был throttled: первичная проверка того ролика не состоялась.
- `classification`: current signal / historical reference / unverified; возраст публикации и свежесть показателей проверять раздельно.
- `brandFit`: выбранный этап воронки, потребность/барьер, почему механизм подходит нашей аудитории. Высокие чужие просмотры сами по себе не обещают прихода гостей.
- `adaptation`: оригинальный хук/структура/сценарная идея; не копия произведения. Отдельно отметить права на исходники/музыку и запреты бренда.

Не смешивать impressions/views/reach/engagement/subscribers. Не складывать разные площадки в «людей клуба». Если доступны два датированных замера, рост вычислять только при сопоставимом определении метрики; один снимок не доказывает недельную динамику.

## Результат для производства

Скаут подготавливает проверяемую единицу-кандидат, а не выдаёт чужую вирусность за готовую стратегию. Профильный отдел отвечает за сценарий/реализуемость и своё решение. Директор утверждает конкретную версию после этих входов.
