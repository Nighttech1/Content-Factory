## Решения по данным, доступам и инструментам (финал)

Эти решения зафиксированы и действуют на все фазы:

- **YouTube (свой канал + конкуренты):** YouTube Data API v3. Ключ лежит в секретах окружения как `YOUTUBE_API_KEY`, агенты читают его оттуда. Стоимость — **0 ₽**.
- **Instagram / TikTok (конкуренты + тренды):** скрапинг через **Apify** (дешёвые акторы, pay-per-result). Старт — на **free-плане** ($5 кредитов/мес), частоту держим так, чтобы укладываться в бесплатное. Ключ Apify — в секретах окружения как `APIFY_TOKEN` (когда подключим).
- **Свои показатели IG/TikTok:** через официальные API аккаунтов (IG Graph при Business-аккаунте) или лёгкий съём Apify. YouTube — через API-ключ.
- **Публикация:** своим агентом-**Публикатором** напрямую через API площадок (IG Graph Publishing, TikTok Content Posting API, YouTube upload). **Metricool/агрегаторы НЕ используем.**
- **Хранение:** мозг (текст: агенты, скиллы, правила, планы) → **GitHub** (весит килобайты, места с запасом). Тяжёлое медиа → **R2/S3**, в репозиторий только ссылки/манифесты в `assets/`. Флешка — только как опциональный бэкап-копия репо, не как рабочее место.
