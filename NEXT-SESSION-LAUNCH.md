## API-ключи для окружения новой сессии (ставит владелец)

> **ВАЖНО про «мозг»:** агенты контент-завода (`projects/vernatun/.claude/agents/*` + скиллы/правила) работают на **подписке Claude Code** — им LLM-ключ НЕ нужен (ни в интерактиве, ни в автономе через облачные scheduled tasks). `AGGREGATOR_API_KEY` нужен **только самому ВЕБ-приложению** (его встроенный `/marketing`-чат и carousel-пайплайн на Polza AI, платно за токены) — это отдельная реализация, она не читает наши `projects/`-скиллы. Если веб используется как витрина/пульт, а агенты гоняются через Claude Code — aggregator можно НЕ ставить.

**🔴 Что реально нужно для ПОЛНОЙ работы:**
- `YOUTUBE_API_KEY` — YouTube аналитика/разведка (уже есть).
- **Генерация картинок** для каруселей/обложек (Claude картинки не рисует): через aggregator (`AGGREGATOR_API_KEY`, модель `openai/gpt-5.4-image-2`) **или** отдельный ключ OpenAI/Ideogram/Flux. Это единственное «платно всегда».

**🟦 Только если хочешь, чтобы САМ ВЕБ думал своим бэкендом (опционально):**
- `AGGREGATOR_API_KEY` + `AGGREGATOR_BASE_URL=https://polza.ai/api/v1` + `AGGREGATOR_DEFAULT_MODEL` — LLM веб-чата `/marketing`, его сценаристов/арт-директора/аналитика и генерации картинок. Платно за токены. Альтернатива — гонять агентов через подписку Claude Code (бесплатно), веб = витрина.

**🟡 Для контента по площадкам (по мере надобности):**
- `APIFY_TOKEN` (или `IG_SCRAPER_API_KEY`) — IG/TikTok разведка/тренды.
- `IG_USER_ID`, `IG_OURS_USERNAME`, `IG_ACCESS_TOKEN` — Instagram Graph (свои метрики/публикация).
- `HEYGEN_API_KEY` — аватары для «обезличенных» рилсов.
- `ELEVENLABS_API_KEY` — озвучка рилсов/YouTube.
- API сайта `vernatunspeakclub.com` — для статей (пришлёшь; укажи имена, напр. `SITE_API_URL` + `SITE_API_TOKEN`).

**⚙️ Инфраструктура (опционально; без них — JSON-fallback без очередей):**
- `DATABASE_URL` — Postgres (персистентность; без него JSON-fallback).
- `REDIS_URL` — очереди рендера (BullMQ) + ingest по расписанию.
- `INGEST_SECRET` — защита ingest-эндпоинта аналитики (нужно в prod).
