# env.manifest.md — что нужно подключить проекту (БЕЗ значений)

> ⚠️ Это манифест, НЕ хранилище секретов. Здесь только ИМЕНА ключей и список коннекторов.
> Реальные значения кладутся в **секреты окружения** (меню окружения → Edit → Network secrets), НИКОГДА в git.
> Назначение: один источник правды «что должно быть подключено», чтобы любая новая сессия/перенос воспроизводились.

## Коннекторы (claude.ai/customize/connectors) — подключаются на аккаунте
| Коннектор | Для чего | Статус |
|---|---|---|
| Google Drive | ассеты: исходники/готовое (`Content Factory/reels/...`); директору — читать бренд-референсы владельца | ✅ подключён |

> Публикаторские агрегаторы (Buffer / Typefully / Metricool / Ayrshare / SocialPilot) **не подключаем**: решено публиковать своим Публикатором через API площадок (Фаза 8). Canva / генерация картинок — зона Арт-директора (Фаза 4), не директора.
