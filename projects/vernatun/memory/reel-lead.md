## Профиль отдела
- Формат по умолчанию: 9:16, 1080×1920, MP4 H.264/AAC; точные значения подтверждает экспорт.
- Короткий ролик начинает с сильного hook; точные длительность и beat-тайминги зависят от исходника и задачи.
- Субтитры точно передают речь, проходят проверку русского/армянского текста и безопасной зоны.
- Стилевые примеры лежат отдельно в `projects/vernatun/references/reels/`; не использовать их как source footage.

## Технический статус
- Веб-framework: `/api/reels/[reelId]/sources` для загрузки, optional Whisper через `WHISPER_BASE_URL`, FFmpeg JSON-монтаж и экспорт MP4.
- Текущая простая авто-нарезка берёт начало каждого source (до 12 секунд до применения профиля), а не выбирает хайлайты по смыслу.
- Текущие субтитры в рендере — базовый drawtext pass; это не готовый брендовый word-level style.
- Текущий `CapCutEditorShell` имеет mock-клипы/дорожки. Сначала проверь live UI и код; не описывай задуманные возможности как включённые.
- Тяжёлые media files не коммитить; локальные reference folders игнорируются Git. Для общего доступа нужен внешний project storage.
