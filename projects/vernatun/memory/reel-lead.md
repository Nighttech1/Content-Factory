# memory/reel-lead.md — память Начальника отдела рилсов

> Личная память агента `reel-lead`. Читает ТОЛЬКО он, перед каждой работой. Чужие не читают этот файл.
> Назначение: копить выученные уроки, чтобы не повторять косяки (самоулучшение через текст).

## Профиль отдела
- Формат: вертикаль 9:16, 1080×1920, mp4.
- Длина: 15–45 сек, крючок в первые 2 сек.
- Субтитры всегда. Тон — из `brief.md` (дружески, на «ты», рус+арм с мягкой подачей).

## Технические дефолты (обновляются опытом)
- FFmpeg-рендер, loudnorm для звука.
- Лого/текст — через `brand-kit` (когда готов).
- Инструментарий: IT Reelsmaker (основной конвейер), Remotion (графика/субтитры), ffmpeg-llm (команды). Если не подключены — руками через FFmpeg/Remotion.
- Исходники: Google Drive `Content Factory/reels/incoming/`; готовое → `.../reels/output/` + ссылка в `assets/`.

  • Исходники пришли как .MOV **464×848** (телефонные превью, низкое разрешение) → апскейл до 1080×1920 (crop-to-fill) + `unsharp`. Всегда закладывать апскейл+резкость для телефонных превью.
  • **Drive-коннектор в сессии не отдавал список файлов/ID** (возвращал только nextPageToken; `fullText` находил, но без ID скачать нельзя). Решение: взять файлы загрузкой в чат или по прямым ссылкам `drive.google.com/file/d/<ID>`. Записано в STATE.md.
  • Музыка: **лицензионные треки (Rocky и т.п.) не вставляем**. Делаю временный синтез-бит (numpy): эпик-билд+риза → импакт+скретч на склейке → армянский фолк. Армянский колорит = лад **D-фригийский-доминантный** + думбек (doum/tek). Живые хлопки/кубики/смех из исходника — поверх грува, через sidechaincompress.
  • Громкость: `loudnorm I=-14 TP=-1.2` (таргет IG/TikTok).
  • Длина 12.5с — снэппи, ок для юмора. Если владелец захочет длиннее — растягивать армянскую часть (нарды/армрестлинг), а не заход.
  • Процесс ревью: перед отдачей всегда клеить contact-sheet с таймкодами (видео) + спектрограмму (звук) и проверять глазами — так ловлю баги тайминга/обрезки (поймал: выходной `-t` обрезал slowmo-шот, чинится обрезкой на входе).
