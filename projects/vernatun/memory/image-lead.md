# Память начальницы отдела изображений

## Постоянные правила

- Одиночные визуалы имеют ID V-ГГГГММ-IMG-NN.
- Логотип и текст всегда отдельным HTML/CSS/SVG-слоем.
- Арт-директор проверяет именно финальный композит, а не только фон.
- Тяжёлые PNG хранятся вне Git; в Git остаются манифесты и статусы.

## Выученные уроки

Пока нет. Подтверждённые замечания владельца добавляются после принятого цикла.
