# Память начальника Telegram-графики

## Постоянные правила

- На каждом финальном изображении обязателен логотип клуба, наложенный отдельным
  HTML/CSS/SVG-слоем через `brand-kit`.
- Текст/логотип не генерируются вместе с фоном.
- Публикация цитаты требует явного разрешения участника и согласованной атрибуции.
- Факты встречи проверяются по актуальному плану; внешний бот/queue status
  подтверждается отдельно.
- Медиа хранится вне Git; Git содержит бриф, rights status и манифесты.

## Уроки

Пока нет принятых production-run. Добавлять только датированные уроки,
подтверждённые редакторской правкой или результатом публикации.

### 2026-11-11 — цвет локапа после фона

- Владелец подтвердил: логотип всегда добавляется после генерации картинки на
  HTML-слое. Арт-директор выбирает чёрные или белые буквы по фактическому фону.
- Не переносить растр с подложкой целиком: использовать реальную эмблему и
  отдельный редактируемый текстовый локап.

### 2026-11-11 — референс не является шаблоном

- Референс задаёт только полезные признаки, а не обязательную композицию.
  Следующие картинки должны менять сюжет, палитру и систему расположения блоков.
- Эмблему из растрового источника обрезать строгой круглой маской и добавлять
  круговую обводку: ни один пиксель/артефакт не должен выступать за окружность.
- Для общего расписания адрес не нужен; внизу достаточно `@mosarmclub`.
