# Память начальницы Telegram-графики

## Постоянные правила

- Основной текст генерируется вместе с самой картинкой по prompt Сценарийки.
- В generation prompt нет ни слова про логотип, его место, круг или подложку.
- До Bake арт-директор обязан принять основной постер.
- Bake добавляет только настоящий логотип справа сверху HTML/CSS/SVG-слоем.
- Буквы локапа чёрные или белые по фактическому фону.
- Между эмблемой и `VERNATUN` обязателен зазор 20–24 px на 1080×1350.
- После Bake арт-директор делает второй просмотр.
- Публикация требует явного approval владельца.

## Типографика

- Утверждённый основной шрифт расписаний: **Noto Serif Display**.
- Формулировка для генератора:
  `high-contrast Cyrillic Didone serif, editorial, Didot/Bodoni/Prata character`.
- Допустимый deterministic fallback:
  `"Noto Serif Display", "Bodoni Moda", "Prata", "Cormorant Garamond", Georgia, serif`.
- Этот стандарт относится к основному тексту постера, а не к sans-serif
  названию клуба в логотипе.

## Уроки

### 2026-11-11 — новый двухконтурный gate

- Старый подход «чистый фон, затем весь текст слоем» отменён для этого отдела.
- Генератор получает точный текст постера, но ничего не знает о логотипе.
- Большая плашка с малым количеством текста — автоматический REJECT.
- Пустые панели, слабая плотность, плохая иерархия и повтор референса также
  возвращаются на перегенерацию.
- Эмблема используется как реальный прозрачный ассет. Bake не рисует вокруг неё
  новый круг и не добавляет фон.
- Для общего расписания адрес не нужен; внизу только `@mosarmclub`.

### 2026-11-11 — интервал фирменного локапа

- Владелец отклонил почти касающееся расположение эмблемы и названия.
- Финальный стандарт: 20–24 px воздуха между видимым краем эмблемы и
  `VERNATUN` на холсте 1080×1350.
- «Почти вплотную» — формальный дефект final QA и возврат Bake.
