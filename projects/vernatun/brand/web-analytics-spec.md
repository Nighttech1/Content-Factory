## Что по факту (инспекция кода)
- Видимая `/analytics` рендерит **только мок**: `AnalyticsShell` берёт всё из `lib/analytics/self-learning-mock.ts` (хардкод), без fetch/store. `/analytics/page.tsx` — редирект на studio-версию, тоже на моках.
- **Реальный пайплайн существует, но «осиротел»:** Prisma/fallback store → адаптеры площадок → ingest → `aggregate-for-analyst` → Analyst-LLM → API-роуты (`/api/analytics/*`) работают, НО компоненты, которые их потребляют (`InsightsFeed`, `PublishedPostsTable`), **нигде не смонтированы**. Смонтированные `RetentionChart`/`RlFeed` получают мок-пропсы, не API.
- **Два несовместимых набора типов:** `lib/analytics-mock.ts` (питает API/store/осиротевшие компоненты) vs `types/analytics.ts` (питает отрисовываемый shell). Не связаны.
- **Адаптеры:** только YouTube + Instagram; **у TikTok адаптера нет** (хотя TikTok по всему UI). **Apify в аналитику не подаётся вообще.** YouTube/IG кривая удержания — **хардкод-фикстуры**; YouTube saves всегда 0.
- **Нет бизнес-KPI:** ни посещаемости встреч, ни лидов/заявок, ни воронки — только vanity (просмотры/сохранения/охваты/удержание). «Conversion Yield» есть лишь в seed-моке осиротевшего пути, и `aggregate-for-analyst` честно помечает это «seed gap fill».
- `aggregate-for-analyst` **выдаёт нормальную структуру** для внешнего Аналитика (`AnalystAggregatesPayload`), но богата она лишь настолько, насколько полон `PostAnalytics` (пусто → моки).
