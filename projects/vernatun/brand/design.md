# design.md — дизайн-токены Вернатун (единый источник стиля)

> Единственный источник визуального стиля проекта. Читает скилл `brand-kit`; агенты стиль НЕ хардкодят.
> Токены сверены с боевым сайтом `vernatunspeakclub.com` (tailwind-config) и бренд-ассетами. Обновлено: 2026-10-30.

## Палитра
| Токен | HEX | Роль |
|---|---|---|
| `parchment` | `#F9F6F0` | основной фон (тёплый светлый) |
| `mist` | `#E8E2D8` | второстепенный фон / разделители |
| `terracotta` | `#C95B36` | **акцент №1** (CTA, хайлайты) — тёплый армянский |
| `sungold` | `#E6B25A` | акцент №2 (тёплое золото, детали) |
| `azure` | `#2A5A84` | акцент-контраст (ссылки, спокойные блоки) |
| `ink` | `#1E2930` | основной текст / тёмный фон |

Градиент-лого/обложки: terracotta → sungold (тёплый) допустим на акцентных плашках.

## Типографика
- **Основной шрифт — Century Gothic** (display + текст). Фолбэк: `CenturyGothic, sans-serif`.
- Армянские вставки — Noto Sans Armenian (фолбэк для армянских рун), по тону брифа (с подстрочником).
- Иерархия (карусель/обложки): заголовок крупный CG Bold; тело — CG Regular; подпись — CG, приглушённый `ink` 70%.

### Хук-кадры — референс владельца от 2026-11-05

- Владелец выбрал типографику по приложенному в чате скриншоту с заголовком «VISUAL HOOKS»: крупный белый жирный гротеск, прописные буквы, плотные строки на тёмном фото/видео. Это отдельное исключение из Century Gothic для заголовков хук-кадров.
- Точная гарнитура по скриншоту не установлена. Ориентир для подбора — Helvetica Neue Bold / Arial Bold; не выдавать сходство за подтверждённую идентификацию шрифта. Для русского текста нужна кириллица.
- Стартовые параметры для примерки: вес 700–800, межстрочный интервал 0.85–0.95, трекинг от -0.04em до -0.02em, 1–3 короткие строки. Размер подбирать по тексту и кадру, без растяжения букв и обрезки; плотность не должна приводить к столкновению строк.
- Белый заголовок (`#FFFFFF`) на достаточно тёмном участке фона; при необходимости локально затемнять фон. Сохранять safe-zone и проверять весь текст на размере телефона.
- Заголовок накладывается HTML/CSS-слоем; в типе A фон генерируется без букв и логотипов. Армянские вставки — Noto Sans Armenian с понятным переводом.
- На первом задании арт-директор и финиш-арт проверяют права на шрифт и фиксируют выбранный файл шрифта и его фактическую загрузку в манифесте. До примерки не обещать точного совпадения с референсом. Сам скриншот остаётся в чате, отдельный ассет в репозиторий не сохранён.

## Логотип
- Ассеты (в вебе): `веб/public/brand/vernatun-logo.svg` (вектор, предпочтительно), `vernatun-emblem.png` (эмблема), `vernatun-logo-lockup.png` (лок-ап).
- Правила: лого — всегда на **HTML-слое** (не вжигать в генерацию фона). Чистое поле вокруг ≥ высоты эмблемы × 0.5. На тёмном фоне — светлая версия, на светлом — основная.
- Размер на карусели 1080×1350: эмблема ~96–120px, угол (обычно нижний), не перекрывает текст/safe-zone.

## Тени / поверхности
- `card`: `0 1px 0 rgba(42,90,132,0.06), 0 12px 40px -16px rgba(30,41,48,0.12)`
- `lift`: `0 18px 50px -24px rgba(42,90,132,0.25)`

## Сетка и отступы
- Карусель/обложка: safe-zone внутрь 7–8% от края (текст/лого не ближе). Базовый ритм отступов — 8pt.
- Форматы кадров: карусель **1080×1350** (4:5), вертикаль/рилс **1080×1920** (9:16), обложка YouTube **1280×720**.

## Тон визуала (из брифа)
Тёплый, уютный, «своё армянское пространство»; дружелюбно, без пафоса и снобизма. Живые фото людей за столом > стоковая глянцевость. Армянские культурные мотивы — тактично (гранат, дудук, орнамент) как акцент, не китч.

## Что НЕЛЬЗЯ
- Менять палитру/шрифт «на глаз» в агентах — только отсюда.
- Вжигать текст/лого в генерацию фона (их кладёт Финиш-арт на HTML-слое).
- Холодные корпоративные градиенты, Inter/системный как основной шрифт (основной — Century Gothic; исключение для хук-заголовков описано выше).
