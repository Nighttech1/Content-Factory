# Маркетинг роста Вернатуна — рабочий метод команды

Версия 1 · 09.11.2026. Это предметные инструкции, а не новая стратегия или заявление о дообучении модели. Канон решений — бренд-бриф и стратегический раздел месячного плана. Численные доказательства: [адресное исследование](growth-market-evidence-20261109.md); первичные условия продукта перепроверяются перед использованием. Никакой метод не даёт разрешение на сбор/расход/рассылку/публикацию.

## 1. Выбирать рынок, а не «всех армян»

Для каждого сегмента записать: ситуация → желаемый прогресс (JTBD) → барьер → текущая альтернатива → критерий выбора → доступный канал → проверка. Отдельно оценить потребность и способность клуба обслужить человека. Пример приоритета: взрослый Москвы с базой языка хочет живого круга и практики; поддержка новичка — способ входа, атмосфера и люди — причина захотеть прийти. Уверенно говорящие создают ценность среды. 36+ желанны, но отдельный регулярный продукт не считается доказанным. Онлайн вне Москвы не считать офлайн-спросом; с нуля обучение не обещать.

STP: сегментировать по задаче/ситуации, выбрать 1–2 приоритета под ресурс и позиционировать опыт относительно конкретной альтернативы. Не угадывать возраст/язык/мотив по фото.

## 2. Числа рынка: единица, год и границы

| Слой | Что требуется | Что нельзя подставлять |
|---|---|---|
| Демографическая база | Население/самоопределение, география/год, первичная таблица и степень проверки | Текущее число потенциальных покупателей |
| TAM | Все люди с определённой задачей и релевантным типом продукта | Вся диаспора или подписчики |
| SAM | Пересечения географии, уровня языка, времени, цены, доступности | Произвольные проценты как измеренные доли |
| SOM | Достижимые при конкретных каналах, периоде, местах и ресурсе | «Возьмём 1% рынка» без воронки |

Для каждой цифры указать URL/таблицу, определение, единицу, период, географию, дату проверки и ограничение. Переписные числа из вторичных таблиц маркировать именно так, если оригинал не прочитан. Не исправлять неответы переписи произвольным коэффициентом. Неизвестные фильтры SAM оставлять неизвестными; калькулятор с допущениями называть сценарием. Широкая база не превращается в доход без цены, частоты, посещаемости и издержек. SOM проверять снизу: релевантно достигли → заинтересовались → записались → пришли → вернулись, с местами на конкретных событиях.

## 3. Конкурировать по задаче и доказательству

Для одной задачи сравнить прямой клуб, языковую школу, бесплатный чат/приложение, культурный досуг и вариант «остаться дома». Матрица: сегмент/JTBD, обещание, фактический опыт, полная цена/доплаты, доступность/расписание, путь записи, помощь, повторяемая ценность, источники и контрсигнал. Разные образовательные/культурные продукты нельзя объявлять хуже только по цене.

Позиционирование оформлять так: «Для [сегмента в ситуации] Вернатун — [категория/опыт], который даёт [результат]; в отличие от [альтернативы] мы показываем [проверяемая фактура]». Доказательство — свои сцены, конкретная помощь, реальный формат/правила и согласованная история участника. «У нас уютно» без фактуры — гипотеза, «мы единственные/лучшие» без сравнительных данных — запрещённое обещание. Не копировать чужие материалы и не приписывать конкуренту отсутствующие слабости.

## 4. Жизненный цикл и содержание

| Этап | Задача контента/операции | Результат и предел |
|---|---|---|
| Привлечение холодных | Настоящие люди/взаимодействие, атмосфера, узнаваемая ситуация, ясная ценность вечера; сильное начало без длинной заставки | Релевантное внимание; просмотры не равны уникальным москвичам |
| Интерес | Продолжение истории и понятное предложение в TG/профиле | Целевой переход/осмысленный интерес, не просто лайк |
| Регистрация | Для уже заинтересованного: «можно одному», помощь, дата/место/полная цена/запись | Первая регистрация на конкретное событие |
| Первый визит | Напоминание и понятная встреча новичка, знакомство с соседями | Пришёл и получил обещанный опыт |
| Возврат | Реальный рекап/связь с людьми/следующий повод | Повтор за выбранное окно, не желание в комментарии |
| Членство | Доказанная регулярная ценность и прозрачная полная выгода | Оплата/продление; намерения показывать отдельно |
| Рекомендации | Дать довольному гостю правдивый материал, которым удобно поделиться | Приведённый новый гость, ветка от опыта, не обязательная ступень после оплаты |
| Реактивация | Уместный повод вернуться ранее участвовавшим; по разрешённому каналу | Возврат из заранее определённой dormant-когорты, не новый клиент |

Сначала желание «хочу к этим людям», затем снижение тревоги «как попасть». FAQ готовится параллельно как инфраструктура, но не заменяет первый привлекательный сюжет. Один материал — один этап и главный CTA. Внешний охват проверять по одному источнику: собственный ролик, рекомендация гостя, согласованная афиша подходящей площадки. Не путать системную дистрибуцию со спамом; сообщения людей/партнёрам только по отдельному разрешению.

## 5. Эксперимент и экономика

Карточка: `сегмент/JTBD → альтернатива → обещание/доказательство → продукт/этап → материал/канал/CTA → событие измерения → источник/единица/знаменатель/окно/когорта → baseline/unknown → гипотеза → срок → минуты/деньги → правило продолжить/изменить/остановить → владелец действия`.

Один активный тест за раз при 0 ₽ продвижения и 180 мин/неделю владельца с ИИ. Учитывать передачи, съёмку, согласования, учёт и ответы. Порог директора без базы — предложенный управленческий ориентир, не норма рынка. Несопоставимые события/публикации не называть строгим A/B; маленькая выборка даёт направление, не причинное доказательство. При отсутствии интереса проверять соответствие аудитории и привлекательность; при интересе без регистрации — предложение/условия; при записи без явки — вход/напоминание; при визите без повторов — опыт/следующий повод. Не лечить всё количеством роликов.

Подписку проверять после фактических расходов, частоты и вместимости. Сравнивать весь платёж участника с разовыми посещениями; для скидочного членства выгода `n × (разовая цена − цена визита) − взнос`. Выручка не прибыль; скидка постоянным гостям может заменить уже существующую выручку. Безлимит и партнёрские места должны быть обеспечены. До подтверждения тарифа — обсуждение/симуляция, не продажа.

## 6. Контракт аналитики и передача ролей

Каждый показатель: значение или null, единица, когорта/период, источник/дата, статус факта/оценки/сценария/цели. `null ≠ 0`; при неизвестном/нулевом знаменателе конверсия не вычисляется. TG и IG не суммируются без дедупликации. Возврат за 30 дней — только календарно созревшие когорты. Рекомендации считать от подходящего опыта, реактивацию — от собственной неактивной базы, а не предыдущей карточки. Имена/контакты не требуются в публичном отчёте; агрегаты не доказывают межплатформенную атрибуцию сами по себе.

- Директор выбирает сегмент, отличие, тест и производственный ID; планирует все стадии, не только афиши.
- Скаут даёт численные границы, предложения и спрос с первоисточниками/годом/выборкой, отдельными контрсигналами и unknown.
- Аналитик проверяет знаменатели, окна, зрелость, источник и экономику; возвращает решение по узкому месту, не советы «больше постить» без связи с данными.
- Отдел получает этап/аудиторию/CTA/фактуру, делает пакет; редактор проверяет обещание/факты/армянский/права, владелец отдельно одобряет.

Ручной handoff сохраняет ID, версию, путь, входы, критерии и статус. Сохранено ≠ получено ≠ стартовало ≠ принято ≠ опубликовано. Runtime веб-чата использует усиленные методы непосредственно в `веб/lib/marketing/prompt.ts`; чтение этого Markdown не является автоматическим подключением его текста к LLM. Реальный эффект промпта проверяется отдельным разрешённым прогоном, не объявляется измеренным по наличию файла.
