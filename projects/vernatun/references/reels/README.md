# Референсы рилсов

Сюда можно положить локальные видео-примеры, которые нужно разбирать как **style reference**. Эти файлы служат для анализа монтажа и оформления; они не являются исходниками для нового ролика и не вставляются в монтаж автоматически.

Каждому файлу добавь запись в `catalog.json`: `id`, `title`, `file`, `source`, `rights`, `tags`, `style_notes`, `active`. Поля `rights`/источник отмечай как неизвестные, если не знаешь условия. Не сохраняй токены или приватные данные.

Большие медиафайлы здесь игнорируются Git-ом. Для использования на другом устройстве нужен внешний проектный media storage; план такого общего хранилища описан в `веб/docs/AGENT_MEDIA_REFERENCES_SPEC.md`.
