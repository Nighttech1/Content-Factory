# Референсы каруселей

Локальная полка примеров каруселей для анализа стиля. Поддерживаемые визуальные примеры: отдельные слайды PNG/JPG/WebP или сетка из 4 кадров (обложка, 2 внутренних, финальный CTA). Используй файл только как **style reference**; пользовательские фотографии для размещения в новых слайдах отмечай отдельно как source assets.

Записи добавляй в `catalog.json`: `id`, `title`, `files`, `source`, `rights`, `tags`, `style_notes`, `active`. Неизвестные авторство/права явно помечай, а не додумывай. Не складывай ключи доступа и персональные данные.

Файлы медиа игнорируются Git-ом. Чтобы полка была общей между устройствами и пользователями, нужен внешний проектный media storage; схема описана в `веб/docs/AGENT_MEDIA_REFERENCES_SPEC.md`.
