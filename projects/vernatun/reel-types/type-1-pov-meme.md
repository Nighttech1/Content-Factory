# Рилс Тип №1 — «POV-мем / контраст-панчлайн»

> Утверждённый формат (владелец, 2026-10-29) на примере Рилса №1 «падел → нарды».
> `reel-lead` делает рилсы этого типа строго по этому пресету — не переспрашивая каждый раз.
> Полные формулировки правил — в `.claude/agents/reel-lead.md` (раздел «Стандарты оформления»).

## Суть формата
Короткий юмор на контрасте: заявлено одно (серьёзный спорт), по факту — другое (армянский колорит).
Арка: **заход «заряженной» команды → «тренировка» → экшн-сетап → резкая склейка → панчлайн-движ → цельный финал**.

## Чек-лист (locked)
1. **Формат:** 1080×1920, 30fps, H.264+AAC, ~10–15с (снэппи).
2. **Верхняя плашка (SEO/POV):** одна строка `pov: <ключевик>` (напр. «pov: армяне пришли на падел»).
   - Шрифт **Century Gothic Bold** (файл у владельца; не в git). Белые буквы + чёрная обводка (borderw~7) + тень, **БЕЗ подложки**. `text_align=C`, 2 строки.
   - **Крупно**, **с первого кадра и до конца, БЕЗ fade-in** (обложка = 1-й кадр с текстом).
   - **НИКОГДА не на лицах** — зона без лиц (нижняя треть, ~y1180–1280). Проверять раскадровкой.
   - Ключевик = сетап (напр. «падел»), а не спойлер панчлайна.
3. **Внутри ролика — никаких меняющихся подписей.** Только верхняя плашка.
4. **Старт — сразу с действия** (обрезать «стояние/взгляд в камеру» в начале).
5. **Склейка-панчлайн:** РОВНО за 1–2 кадра ДО контакта (мяч в кадре, касания нет) → сразу следующий слайд. **Хард-кат, без вспышек.** Перед действием показать подводку (подброс мяча), не только кульминацию.
6. **Финал:** цельный дубль не кромсать, довести до естественной точки (рукопожатие и т.п.).
7. **Звук/музыка:** владелец присылает mp3 → вшиваю точно (можно двухчастно: боевой → армянский с момента панча; фейды, синхрон под склейку). ⚠️ famous (Eye of the Tiger и т.п.) вшитый = Content-ID на IG → для паблика ставить встроенной музыкой площадки или royalty-free. Выдача «под музыку площадки» — без вшитой музыки, живой звук тише.
8. **Бренд/тон:** дружески на «ты», рус+арм, без снобизма (`brand/brief.md`). CTA в кадре нет — приглашение в подпись/первый коммент.
9. **Гейт:** Редактор (когда есть) → явный апрув владельца. Тяжёлое медиа — не в git.
