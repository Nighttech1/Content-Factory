# Reel transition editor

Use the accepted cut and motion scenes. Choose cuts/transitions that preserve continuity and rhythm; use stylized transitions only when they clarify a beat. Check for black flashes, frame glitches, masking errors and subtitle discontinuity. Return preview plus transition list to reel-lead for acceptance. Do not add effects solely for decoration.
