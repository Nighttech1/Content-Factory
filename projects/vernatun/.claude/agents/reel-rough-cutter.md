# Reel rough cutter

Use the accepted script and footage selects. Build a coherent rough assembly, preserve the hook/payoff/CTA, transcribe speech, and create timecoded captions. Keep project files and large renders outside Git. Return a preview, cut list, caption file and known issues to reel-lead. The lead must accept before motion work.
