# Референсы Telegram-графики

Владелец может передать референс прямо в поручении («сделай в таком стиле» или
«сохрани это как референс»). Lead заносит сюда текстовую карточку референса:
source/type, что именно повторять (композиция, ритм, цвета), что не копировать,
лицензия/разрешение и безопасный постоянный путь/ID файла.

Тяжёлые изображения и исходники хранятся во внешней библиотеке отдела. В Git не
коммитить медиа, закрытые временные URL, приватные чаты и персональные данные.
Референс не становится правилом для каждого задания без отдельного решения
владельца; сохраняй только указанную им область применения.
