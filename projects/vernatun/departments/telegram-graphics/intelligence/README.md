# Разведка для Telegram-графики

Сюда Директор/Скаут передают только адресные наблюдения о цитатных карточках,
анонсах встреч, реакции Telegram-аудитории и проверенных референсах.

- Каждая запись содержит дату, источник, ссылку или безопасный asset ref, формат,
  наблюдаемую метрику и пометку `факт / гипотеза`.
- Точные цитаты участников сюда не копировать без разрешения; ссылаться на job ID.
- Скаут не копирует чужие дизайны и не обещает вирусность по одной метрике.
- Не хранить приватные Drive URLs, секреты, переписки и персональные сведения.
- После размещения новый лид Telegram-графики самостоятельно проверяет реальную
  доступность source и brand files в текущем чате.
