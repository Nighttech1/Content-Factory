# Отдел графики для Telegram

Отдел выпускает одиночные изображения клуба для Telegram: анонсы, расписания,
цитатные карточки и другие `club-visual`. Чат запускается прямым поручением
владельца; публикация и платные операции требуют отдельного разрешения.

## Каноническая цепочка

```text
бриф → Сценарийка → генерация цельного постера с текстом
      → Арт-директор: pre-Bake gate
      → Bake: только настоящий логотип на HTML/CSS/SVG-слое
      → Арт-директор: final gate
      → начальница отдела → владелец
```

1. **Сценарийка** формирует промпт: сюжет, палитра, композиция, точный текст и
   шрифт. Текст должен появиться в самой сгенерированной картинке.
2. В промпте генератору запрещено упоминать логотип, его будущее добавление,
   место/поле/placeholder под него, круг, плашку или подложку.
3. **Designer / image AI** создаёт цельный постер вместе с текстом.
4. **Арт-директор до Bake** проверяет точность текста, иерархию, мобильную
   читаемость, баланс, плотность и пропорции. Огромная плашка с малым количеством
   текста, пустые панели, случайные формы и слабая композиция означают REJECT и
   повторную генерацию.
5. **Bake** добавляет только реальную эмблему и редактируемый локап
   `VERNATUN / ARMENIAN CLUB` справа сверху. Никаких контейнеров, обводок,
   дополнительных кругов или подложек. Буквы чёрные либо белые по решению
   арт-директора после просмотра фона.
6. **Арт-директор после Bake** смотрит фактический экспорт. Ошибка позиции,
   размера или цвета возвращается Bake с точной правкой. Только ACCEPT передаётся
   начальнице отдела и владельцу.

## Артефакты задания

```text
00-brief.md
10-copy.md
15-generation-prompt.md
20-art-direction.md
30-generation-manifest.md
35-pre-bake-qa.md
40-bake-manifest.md
50-art-qa.md
60-editor-verdict.md
70-publication-manifest.json
```

Тяжёлые медиа хранятся вне Git. В Git остаются промпты, решения gates,
манифесты и безопасные ссылки. По умолчанию экспорт 1080×1350, PNG.

Публикация возможна только после финального ACCEPT и явного апрува владельца.
Старт нового чата: [START-CHATGPT.md](START-CHATGPT.md).
