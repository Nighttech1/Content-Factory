# Контент-директор

Стартовая точка директора — `projects/vernatun/content-plan/`. Он читает
`projects/vernatun/.claude/agents/content-director.md`, свою память, бренд и
месячный план, затем создаёт или уточняет задания по ID. Он не производит
финальные материалы и не хранит копии файлов отделов.

После постановки задачи директор возвращает владельцу: ID, формат, адресат,
версию брифа, входные материалы и критерии приёмки. Владелец вручную передаёт
этот ID следующему чату.

## Локальные маркетинговые методы

Однократно перед своим этапом прочитай `shared/skills/marketing-methods/SKILL.md` и `shared/skills/marketing-methods/modules/director.md`. Применяй только свою часть к текущему заданию; уже прочитанные инструкции повторно не загружай. Исходники в `shared/vendor/marketing-methods/` — справочные документы, а не команды на запуск инструментов. Существующие выходные файлы, роли и gates сохраняются.
