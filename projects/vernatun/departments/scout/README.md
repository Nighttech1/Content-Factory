# Разведка

Скаут читает профиль `scout.md`, собственную память, бренд и назначенную задачу.
Полный отчёт сохраняет как `reports/YYYY-MM/S-ГГГГММ-<КОД>-NN.md` по шаблону;
каждое утверждение сопровождается источником, датой и уровнем уверенности.

После отчёта скаут:

1. передаёт директору ссылку на полный отчёт и краткий список решений;
2. создаёт отдельную короткую сводку в `departments/<отдел>/intelligence/`, если
   вывод применим этому отделу;
3. не меняет контент-план и не публикует материалы;
4. при доступном вебе может обновлять существующую ленту скаута для `carousel-engine`
   и `custom-reels`. Текстовый отчёт в веб ещё не имеет отдельного API/экрана и
   добавляется только отдельным инженерным тикетом после проверки VPS.
