# Разведка

Скаут читает профиль `scout.md`, собственную память, бренд и назначенную задачу.
Отчёты сохраняет в указанный директором файл бренда или рядом с конкретным ID;
каждое утверждение сопровождается источником, датой и уровнем уверенности.
Скаут не меняет контент-план и не публикует материалы.
