# Библиотека «Дизайн 1…N»

Владелец присылает чужой рилс и просит разобрать его оформление. Это отдельная
аналитическая ветка; производство нашего рилса не начинается без ID и исходников.

## Реестр

| ID | Название | Версия | Источник | Просмотр / статус | Профиль |
|---|---|---|---|---|---|

Профилей пока нет. Скриншот «VISUAL HOOKS» — предпочтение типографики,
а не разобранное видео; см. brand/design.md.

Подробный регламент: `shared/skills/reel-reference-analysis/SKILL.md`.
Единственный реестр дизайнов — эта папка `designs/`; параллельные библиотеки не создавать.

## Разбор и применение

1. Принять доступный файл/ссылку, автора и пожелания владельца. Присвоить следующий
   свободный DESIGN-001 (Дизайн 1) и файл DESIGN-001.md по _TEMPLATE.md.
   Это ID референса, отдельный от производственного V-…; номера не переиспользовать.
2. Проверить и просмотреть видео: типографика, сетка, цвета, субтитры, хук,
   монтажный ритм, motion, переходы, звук, CTA. Для каждого вывода — тайм-код,
   наблюдаемый параметр и отдельно гипотеза о его функции. Неизвестный шрифт/easing
   не выдавать за установленный факт. Просмотр кадров не доказывает плавность motion.
3. Сохранить версию профиля и статус: частичный / разобран / адаптирован
   Арт-директором. Указать просмотренные диапазоны и ограничения.
4. Владелец вручную переносит запрос Арт-директору: ID, версия, файл, ожидаемый
   результат, критерии и блокеры. Запись файла не равна передаче/получению задания.
5. В 00-brief.md нашего рилса выбрать ID/версию и конкретные приёмы. Арт-директор
   адаптирует их в 20-art-direction.md и motion-brief.md с тайм-кодами нашего видео.
   Сам профиль не отменяет бренд: конфликты решает владелец.
6. Проверить реальный рендер по выбранному профилю и motion-брифу. Не копировать
   неразрешённые чужие кадры, текст, музыку и логотипы. Видео и кадры вне Git;
   в Git только текст и безопасные ID/ссылки без секретов.

## Передача большого видео

Доступная ссылка на скачивание оригинала из согласованного хранилища либо
облегчённый MP4 H.264/AAC до лимита текущего интерфейса (например, до 45 МБ при
ограничении 50 МБ), 720×1280/1080×1920 с исходным fps, таймингом и звуком.
Для мелких букв — оригинальные кадры. Можно прислать части с исходными тайм-кодами,
порядком и небольшим перекрытием на стыках. Ссылка на пост не гарантирует доступ
к самому видео. Проверять действительные возможности загрузки в новом чате.
