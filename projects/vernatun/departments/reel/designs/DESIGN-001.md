## Настройки
- Композиция: речь/лицо — центральный доминантный объект, графика — сверху/сбоку без перекрытия глаз; соблюдать mobile safe zone.
- Типографика: наблюдается крупный плотный текст с резкой иерархией; **точное семейство и параметры не установлены**. Для Вернатуна — `Noto Serif Display Black 900` по `brand/design.md`; мелкая служебная подпись по бренду.
- Цвет: референс white / dark / bright blue. У Вернатуна применяются существующие `parchment`, `ink`, `azure`, `terracotta` без копирования чужого стиля как бренд-токена.
- Субтитры: наблюдаются текстовые акценты, но word-level timing по выбранным кадрам не подтверждён.
- Motion/easing/продолжительность переходов: **не измерено** по контактным кадрам; необходим отдельный покадровый просмотр прежде чем заявлять точные значения.
- Звук: AAC присутствует; не анализировался, музыкальные акценты не воспроизводились при исследовании.
- Монтаж: чередование живого talking head и полноэкранной графики; точное число склеек не установлено.
- CTA: из кадров видна Instagram-подписка/подпись, это UI оригинального Reels, а не наш CTA.

## Рецепт для Вернатуна
- SIMPLE юмористический Reels: 0–2 склейки, два коротких субтитрованных хука максимум, сохранять лица и паузу перед шуткой.
- POLISHED объяснение/разбор: talking head → один полноэкранный смысловой экран → talking head + выделенное слово. Оформление адаптируется под бренд.
- SHOWCASE: маска-круг / mask-rectangle с Remotion только по отдельной задаче, рендер и QA обязательны.
- Технические правила: `shared/skills/vernatun-reel-editing-craft/SKILL.md`.
- Права: **никакие оригинальные кадры, оригинальная музыка, тексты автора или интерфейс Instagram не входят в монтаж Вернатуна**.
- Статус приёмки: арт-директор и редактор ещё не выполняли реальный review/рендер; документ — аналитическая карточка, не готовый Reels.
