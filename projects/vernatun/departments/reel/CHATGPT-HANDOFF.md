# Передача отдела рилсов в обычный ChatGPT

Дата: 2026-11-09. Репозиторий Nighttech1/Content-Factory, целевая ветка main.

## Решения владельца

- Отдельный чат отдела внутри проекта Вернатун в ChatGPT; Claude не обязателен.
- Внешнее общение — 🧑‍💼 Клиент, женский род, на «ты»; контент-роль — reel-lead.
- Ручная эстафета по ID: владелец переносит задания, чат не запускает другие
  чаты/субагентов и ничего не публикует. Не запускать производство до ID,
  подтверждённых исходников, прав и критериев.
- Арт-директор выдаёт motion-brief с тайм-кодами. Remotion при рабочем runtime;
  FFmpeg — монтаж и экспорт. План/статичный кадр не доказывает готовый motion.
- Хук-шрифт: скриншот «VISUAL HOOKS», белый жирный гротеск капсом, плотные строки.
  Точная гарнитура неизвестна, см. brand/design.md. Скриншот как бинарный файл
  в Git не переносился; при необходимости точного сравнения запросить снова.
- Чужие рилсы анализировать и сохранять в профили «Дизайн 1…N» с тайм-кодами,
  параметрами, неизвестными и правилами адаптации. Реестр пока пуст.
- Качество/апскейл: диагностика, короткая проба, сравнение, экспорт, просмотр.
  Runway не обязателен. GPU/модель проверять. Colab — интерактивный бесплатный
  кандидат, без API-сервера/обхода лимитов. Платный billing/API не активировать.

## Что фактически выполнено

Прочитаны инструкции и бренд, подготовлены текстовые регламенты, шаблоны и память.
В прошлой среде FFmpeg/FFprobe 7.1.5 запускались, FFmpeg Media Toolkit был
установлен и doctor проходил; после пересоздания среды установка не сохранилась.
Remotion/GPU/AI-модель не были подтверждены рабочим рендером. Производства,
обработки видео, подключения Colab/API и публикации не было. ID и исходное видео
для первого задания владельцем не переданы. Готового улучшенного рилса нет.

## Переносимость

Git хранит текст, а не весь чат: профили, правила, шаблоны, решения и память.
CLAUDE.md и .claude/agents/ читаются как документы и в ChatGPT. Секреты,
OAuth, выбранный Google-аккаунт, облачные плагины, GPU и исполняемая среда
не переносятся. Настройка проекта ChatGPT сама по себе не гарантирует доступ
к GitHub, запись в Git или запуск FFmpeg. В новом чате сначала проверить
реальное чтение файлов, затем отдельно исполнение, запись и просмотр видео.
Исторические заявления STATE.md о готовности/подключениях не доказательство.

Если GitHub недоступен, владелец может передать архив репозитория или пакет
инструкций. Явно фиксировать commit/дату снимка и не называть его живой синхронизацией.
Вложения разных чатов автоматически не наследуются. Медиа — во внешней библиотеке;
Git только безопасные ID/ссылки. Публикация, платные API и production — запрещены
без нового явного разрешения владельца. Сначала отчёт готовности.
