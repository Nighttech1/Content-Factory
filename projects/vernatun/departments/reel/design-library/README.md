# Библиотека оформления рилсов

Пользователь присылает видео и просит: «Разбери и сохрани как новый дизайн».
Разбор выполняется по `shared/skills/reel-reference-analysis/SKILL.md`.
Для применения: «Для <ID рилса> используй Дизайн N, версия v1».

Номера последовательные, технический формат `DESIGN-001`; существующие номера
не переиспользовать. Карточки хранят наблюдения отдельно от рецепта адаптации.
Видео, кадры и закрытые ссылки в Git не сохраняются.

| Дизайн | Версия | Источник / краткое описание | Карточка | Ограничения |
|---|---|---|---|---|

Пока нет разобранных видео. Скриншот «VISUAL HOOKS» от 2026-11-05 учтён
в `projects/vernatun/brand/design.md` как предпочтение хук-типографики;
он не является разбором рилса и номер дизайна ему не присвоен.
