# Отдел YouTube

Перед работой прочитай `scriptwriter-youtube.md` или `video-producer.md` по
своей роли, соответствующую память, `shared/pipelines/youtube/README.md`, план
и `jobs/<ID>/`. Создай папку задания по `_TEMPLATE/`.

В Git живут сценарий, план производства, манифест и вердикт. Видео, аудио и
изображения — только во внешнем хранилище со ссылками и указанием прав.
