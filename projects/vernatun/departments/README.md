# Отделы контент-фабрики «Вернатун»

Эта папка — точка входа для специализированных чатов. Перед работой агент
сначала читает свой профиль в `.claude/agents/`, затем README своего отдела,
свою память и конкретное задание по ID.

## Источники данных

| Что | Каноническое место |
|---|---|
| Цель, канал, CTA, дата, статус и ID | `projects/vernatun/content-plan/ГГГГ-ММ.md` |
| Производственная эстафета отдела | `projects/vernatun/departments/<отдел>/jobs/<ID>/` |
| Текстовые черновики | `projects/vernatun/drafts/ГГГГ-ММ/` |
| Уроки роли | `projects/vernatun/memory/<роль>.md` |
| Тяжёлые медиа | внешнее хранилище; в Git — ссылка и манифест |

Не копируй месячный план в папки отделов. В `00-brief.md` фиксируются только
ссылка на план, версия брифа и уточнения, принятые для конкретного производства.

Директор создаёт рабочую папку до передачи задания: `V-202611-CAR-01` сразу идёт
в `carousel/jobs/V-202611-CAR-01/`, а `V-202611-REL-01` — в `reel/jobs/V-202611-REL-01/`.
Правила кодов — в `content-plan/README.md`.

## Активные отделы

| Отдел | Папка | Лид |
|---|---|---|
| Карусели | `carousel/` | `scriptwriter-carousel` / начальник отдела каруселей |
| Рилсы | `reel/` | `reel-lead` |
| Статьи | `article/` | `scriptwriter-article` |
| YouTube | `youtube/` | `scriptwriter-youtube` + `video-producer` |
| Графика Telegram | `telegram-graphics/` | `telegram-graphics-lead` |
| Разведка | `scout/` | `scout` |
| Аналитика | `analyst/` | `analyst` |
| Редактура | `editor/` | `editor` |

Контент-директор работает из `content-plan/`, но его маршрут также описан в
`director/README.md`. Мультсторис появятся в этом списке только после создания
отдельного профиля роли и согласования её пайплайна.

## Как запустить чат одной строкой

Выберите репозиторий `Content-Factory` для нового чата и отправьте одну из команд:

| Чат | Команда владельца |
|---|---|
| Контент-директор | `Ты — Контент-директор Вернатуна. Прочитай свой профиль, свою память и content-plan. Работай только с заданиями по ID.` |
| Начальник каруселей | `Ты — Начальник отдела каруселей Вернатуна. Прочитай projects/vernatun/.claude/agents/carousel-lead.md и действуй только по ID задания.` |
| Финиш-арт / бейк | `Ты — Финиш-арт-директор Вернатуна. Прочитай свой профиль и выполни только HTML-бейк для ID задания.` |
| Начальник рилсов | `Ты — Начальник отдела рилсов Вернатуна. Прочитай projects/vernatun/.claude/agents/reel-lead.md и действуй только по ID задания.` |
| Начальник графики Telegram | `Ты — начальник отдела Telegram-графики Вернатуна. Прочитай projects/vernatun/departments/telegram-graphics/START-PROMPT.md и работай по ID TGP.` |
| Редактор | `Ты — Редактор Вернатуна. Прочитай свой профиль и выдай вердикт только по ID задания.` |
| Скаут | `Ты — Скаут Вернатуна. Прочитай свой профиль и подготовь отчёт только по назначенному ID исследования.` |
| Аналитик | `Ты — Аналитик Вернатуна. Прочитай свой профиль и подготовь выводы только по назначенному периоду или ID.` |

После первой команды достаточно передавать: `Возьми в работу <ID>`. Агент обязан
сам открыть свой профиль, папку отдела, память и файлы задания.

Полные готовые тексты для новых чатов: `carousel/START-PROMPT.md` и
`reel/START-PROMPT.md`.
