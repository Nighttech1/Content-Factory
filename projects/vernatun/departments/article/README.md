# Отдел статей

Перед работой прочитай профиль `scriptwriter-article.md`, свою память,
`shared/pipelines/article/README.md`, план и `jobs/<ID>/`.
Перед выбором темы проверь `intelligence/`: там лежат только адресные сводки скаута
для статей, а не копии всех его отчётов.

Создай `jobs/<ID>/` по `_TEMPLATE/`; в нём хранятся ссылка на бриф, статья,
визуальные брифы, манифест ассетов и вердикт редактора. Тяжёлые изображения не
кладутся в Git. Публикация статьи остаётся ручной до отдельного решения владельца.
