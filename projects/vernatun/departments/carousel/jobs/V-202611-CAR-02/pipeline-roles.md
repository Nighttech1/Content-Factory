# V-202611-CAR-02 · Роли и контрольные точки

В этой волне реальные отдельные субагенты не запускались: я последовательно выполнила роли внутри одного чата и зафиксировала доказательства каждого перехода.

| Роль | Что делает | Что считается доказательством |
|---|---|---|
| 🧑‍💼 Клиент | Даёт тему, формат, CTA и критерии приёмки | ID, brief, ограничения |
| 🎓 Тренер | Проверяет, что есть правила типа 1, логотип, референсы героини и QA-инструменты | список assets/rules и stop-rules |
| 🧱 Архитектор | Разбивает карусель на слайды и слои | slide map и chain до генерации |
| ✍️ Сценарист | Пишет hook, 3×4 пары фраз, final/CTA | утверждённый script.md |
| 🎨 Art Director | Задаёт сцены, позы, зоны текста и проверяет разнообразие кадров | six prompts + background montage |
| 🖼️ Генератор | Создаёт только чистые AI-фоны с героиней | шесть исходных PNG |
| 🔍 Background QA | Отбраковывает фон с логотипом, псевдотекстом, карточками или без героини | принятый montage |
| 🧩 Bake | Накладывает текстовые карточки, переводы и канонический логотип | baked PNG 1080×1350 |
| 🎨 Design QA | Проверяет композицию, читаемость, safe zones и единообразие | contact sheet + отдельные слайды |
| 🔧 Fixer | Исправляет только найденные дефекты и возвращает на повторную проверку | diff/повторный QA |
| 🧪 Final QA | Проверяет размеры, количество слайдов, 3 фразы на каждом среднем слайде и визуальный лист | машинный + визуальный отчёт |
| 🚀 Деплоер | В этой задаче не используется; локальная передача архива | локальный zip, без публикации |
| 🧑‍💼 Клиент | Принимает или возвращает с конкретными замечаниями | `CLIENT_REVIEW` → `согласовано` |

## Chain

`brief → trainer → architecture/script → art direction → generation → background QA → bake → design QA → fixer (если нужен) → final QA → client review`

Жёсткие стопы: bake нельзя начинать на непринятых фонах; средние слайды нельзя сдавать без ровно трёх пар; логотип нельзя генерировать внутри фона; клиенту нельзя отдавать результат до визуального contact-sheet review.
