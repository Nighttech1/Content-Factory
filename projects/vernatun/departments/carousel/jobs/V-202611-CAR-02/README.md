# V-202611-CAR-02 · Тип 1 «Словарь»

Новая карусель Vernatun с армянскими фразами для новичка на разговорной встрече.

## Что открыть

1. Сначала `final_png_v3/contact-sheet-final.png` — общий просмотр шести слайдов.
2. Затем отдельные PNG `01-hook.png` … `06-final.png` — проверка деталей и читаемости.
3. `V-202611-CAR-02-gallery.html` — локальная HTML-галерея без генерации и без внешних API.

Это именно baked-результат: фоны, HTML/CSS-логика текстовых карточек и канонический логотип уже сведены в PNG.

## Состав

- 1 hook-слайд с одной AI-типографической фразой.
- 4 обучающих слайда, на каждом ровно 3 армянские фразы и 3 русских перевода.
- 1 final/CTA-слайд с приглашением на разговорную встречу Vernatun.

Статус: готово к клиентской визуальной приёмке (`CLIENT_REVIEW`).
