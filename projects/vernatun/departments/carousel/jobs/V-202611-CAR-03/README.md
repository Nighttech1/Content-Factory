# V-202611-CAR-03

Финальная тестовая карусель Vernatun, тип 1 «Словарь».

Состав архива: 7 PNG, contact sheet, сценарий, журнал gates и bake-скрипт.

## Визуальная система

- 1080×1350, единый вертикальный формат.
- Логотип — только актуальный crop из референса, строго top-right.
- Брендовый fallback-шрифт — Montserrat variable из `shared/brand/fonts/`; Armenian — Noto Sans Armenian.
- Карточки: полупрозрачный terracotta/orange, белый текст, компактные отступы.
- Hook/CTA: крупная AI-типографика, HTML не используется для этих двух текстовых блоков.

Статус: готово к клиентскому просмотру.
