# Отдел каруселей

## Что читать при старте чата

1. `AGENTS.md`, `CLAUDE.md`, `ACTIVE_PROJECT`.
2. Свой профиль роли из `projects/vernatun/.claude/agents/`.
3. `projects/vernatun/departments/README.md` и этот файл.
4. `projects/vernatun/memory/<своя-роль>.md`.
5. Строку задания `V-ГГГГММ-NN` в месячном плане.
6. `jobs/<ID>/` и `shared/pipelines/carousel/README.md`.
7. `intelligence/` — только адресные сводки скаута по этому формату.

## Папка одного задания

Создай `jobs/<ID>/` копированием структуры `jobs/_TEMPLATE/`. Порядок файлов —
эстафета, а не параллельные версии одного и того же брифа:

```text
00-brief.md                    → директор / лид: ссылка на план и уточнения
10-script.md                   → сценарист: текст слайдов и подпись
20-art-direction/              → арт-директор: единый визуальный замысел
  background-prompts.md        → дизайнер: только фоны без букв и лого
  bake-task.md                 → финиш-арт: HTML-бейк по каждому слайду
30-design-manifest.md          → дизайнер: ссылки на утверждённые фоны
40-bake-manifest.md            → финиш-арт: ссылки на PNG и HTML-элементы
50-art-qa.md                   → арт-директор: QA композита
60-editor-verdict.md           → редактор: ✅ / ❌ и правки
```

## Обязательный тип A: генеративный фон + HTML-бейк

Арт-директор выбирает тип A, когда атмосфера создаётся генеративными фонами,
а читаемый бренд-контент должен быть управляемым. В `bake-task.md` он указывает
для каждого слайда: фон, safe-zone, точный текст, логотип, армянские плашки,
CTA и выравнивание. Дизайнеру запрещено генерировать эти элементы на фоне.

Финиш-арт кладёт элементы HTML/CSS/SVG-слоем и выдаёт PNG `1080×1350` плюс
манифест. Без `bake-task.md` он не импровизирует и возвращает задачу арт-директору.

## Готово, когда

У каждого ID есть заполненные файлы от `00-brief.md` до `60-editor-verdict.md`,
а тяжёлые изображения лежат во внешнем хранилище и указаны ссылками. Публикация
возможна только после редакторского ✅ и явного апрува владельца.
