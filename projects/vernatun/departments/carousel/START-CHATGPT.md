# Переезд в ChatGPT — карусели Вернатуна

Срез состояния: 2026-11-09. Репозиторий: https://github.com/Nighttech1/Content-Factory,
ветка `main`. Рекомендуемое название чата в проекте ChatGPT «Вернатун»:
«Карусели · начальник отдела». Этот файл содержит контекст переезда, а не новый
производственный бриф. Правила и память читаются заново из актуальной ветки.

## Подключение

- Подключи GitHub и выбери репозиторий, если текущий режим ChatGPT это позволяет.
  В публичном репозитории чтение возможно также через доступные web-инструменты;
  само наличие URL не означает, что чат прочитал файлы.
- Если доступа к GitHub нет, приложи перечисленные ниже файлы или архив актуального
  `main`. Это снимок: будущие изменения автоматически в него не попадут.
- Обычный чат ChatGPT не получает файловую систему, терминал, запись в GitHub,
  ключи и MCP из прежней среды. Проверь доступность каждого необходимого действия.
  При доступе только на чтение выдавай изменения/артефакты для ручного сохранения,
  не заявляй о записи в репозиторий. Инструменты генерации и рендера проверяй отдельно.
- Вложения старого чата не переезжают через Git. Исходный скриншот «VISUAL HOOKS»
  при необходимости приложить повторно; его описание уже есть в `brand/design.md`.
