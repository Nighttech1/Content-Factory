# content-plan/ — контент-план Вернатуна

## Решение владельца от 16.11.2026

Для `vernatun` обязательно прочитать `projects/vernatun/cmo/content-responsibility.md`.
CMO задаёт объём, направления, аудиторию, цель, показатели, каналы и период.
Начальники отделов сами подбирают темы, создают ID/jobs и отвечают за производство
и выпуск через действующие проверки и разрешения. Это заменяет старые требования
получить конкретную тему и готовую папку от директора. Для других проектов
порядок не меняется. Прямой запуск TGP владельцем сохраняется.


Единый месячный план содержит распределение CMO и тематические строки отделов.
В распределении: период, отдел, количество, направление, формат/канал,
аудитория, цель, показатель результата и ограничения. Тема не обязательна.
Начальники отделов выбирают темы и заполняют ID и jobs в том же плане.
Распределение и материалы не складываются как два разных объёма;
оригиналы считаются по уникальным ID, кросс-постинг учитывается отдельно.

## Правила
- Один файл на месяц: `ГГГГ-ММ.md` (например `2026-11.md`), по шаблону `_TEMPLATE.md`.
- Каждая единица контента имеет уникальный ID с кодом отдела и прослеживается к KPI «люди на живых встречах».
- Статусы единицы: `план` → `в работе` → `на апрув` → `одобрено` → `опубликовано`.

## Поля единицы
| Поле | Что это |
|---|---|
| ID | `V-ГГГГММ-<КОД>-NN`, например `V-202611-CAR-01` |
| Столп | один из 5 (встречи / комьюнити / язык / культура / платформа) |
| Формат | карусель / рилс / youtube / статья |
| Канал | IG / TG / TikTok / YouTube / сайт |
| Тема | выбирает начальник отдела |
| CTA | конкретный призыв (на встречу / в TG / в комнаты) |
| Дата | неделя или дата выхода |
| Статус | см. выше |

## Связь с встречами
CMO задаёт цель и объём поддержки подтверждённых встреч. Начальники отделов
сами выбирают темы и связки материалов.

## Коды отделов

| Код | Отдел | Рабочая папка |
|---|---|---|
| `CAR` | карусели | `departments/carousel/jobs/<ID>/` |
| `REL` | рилсы | `departments/reel/jobs/<ID>/` |
| `ART` | статьи | `departments/article/jobs/<ID>/` |
| `YTB` | YouTube | `departments/youtube/jobs/<ID>/` |
| `TGP` | Telegram-графика: цитаты участников и анонсы встреч | `departments/telegram-graphics/jobs/<ID>/` |
| `IMG` | Отдел изображений: одиночные постеры и визуалы | `departments/image/jobs/<ID>/` |
| `MST` | мультсторис, после создания отдела | `departments/multistory/jobs/<ID>/` |

Начальник отдела выбирает свободный ID по плану и jobs, создаёт папку
задания и заполняет `00-brief.md` до производства. Месячный план хранит только плановую строку и ссылку на папку задания;
рабочие документы не дублируются в нескольких местах.

Старые ID в утверждённых планах не переименяются. Новый формат действует для всех
новых заданий.
