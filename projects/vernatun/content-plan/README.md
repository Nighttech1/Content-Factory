# content-plan/ — контент-план Вернатуна

Здесь живут месячные планы, которые выдаёт **Контент-директор**. Из них команда (пайплайны) берёт задания.

## Правила
- Один файл на месяц: `ГГГГ-ММ.md` (например `2026-11.md`), по шаблону `_TEMPLATE.md`.
- Каждая единица контента имеет уникальный ID и прослеживается к KPI «люди на живых встречах».
- Статусы единицы: `план` → `в работе` → `на апрув` → `одобрено` → `опубликовано`.

## Поля единицы
| Поле | Что это |
|---|---|
| ID | `V-ГГГГММ-NN` (V = Вернатун) |
| Столп | один из 5 (встречи / комьюнити / язык / культура / платформа) |
| Формат | карусель / рилс / youtube / статья |
| Канал | IG / TG / TikTok / YouTube / сайт |
| Тема | рабочая формулировка |
| CTA | конкретный призыв (на встречу / в TG / в комнаты) |
| Дата | неделя или дата выхода |
| Статус | см. выше |

## Связь с встречами
Под каждую живую встречу (~5/мес) директор собирает кластер: тизер → анонс → напоминание → рекап.
