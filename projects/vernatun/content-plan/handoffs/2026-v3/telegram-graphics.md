# Необязательное оформление Telegram ·v3

Роль telegram-graphics-lead запускается только личным сообщением владельца. Директор не назначает TGP-ID и не запускает этот чат. Если владелец хочет специализированное оформление:3 обложки для уже существующих нижних CAR от 13.11/27.11/11.12. Это замена/переупаковка обложки, не новая публикация поверх 37 оригиналов. Лид сам выбирает свободный TGP по своему START-PROMPT и связывает его с parentCAR; требует подтверждённую карточку события и права. Если бюджета/исходников нет — использовать готовую обложку карусели, без отдельной задачи.

> Моё личное поручение: оформи обложку подтверждённого анонса из[CAR-ID]. Прочитай свой START-PROMPT, сам выбери свободный TGP-ID. Факты брать из карточки события; не публикуй. Это оформление существующего поста, не ещё одна афиша.
