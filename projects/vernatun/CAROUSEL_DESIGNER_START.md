# Старт чата с Дизайнером каруселей

Открой Codex с репозиторием Content Factory и выбери агента `carousel_designer`. Картинки, которые должны попасть в конкретную карусель, приложи отдельно как source assets. Для постоянного визуального примера добавь файл/запись отдельно в `projects/vernatun/references/carousels/`.

Пример задания:

> Подготовь карусель Вернатуна на тему [тема] для [аудитория]. Для стиля используй референс `[reference ID или файл]`: извлеки композицию, типографику, палитру и ритм, но адаптируй под брендбук Вернатуна и не копируй текст/графику дословно. Сначала покажи разбор стиля и сценарий по слайдам, затем перечисли source assets и критерии визуальной приёмки.

Codex-роль подготавливает и проверяет сценарий/план. Фактическая генерация слайдов должна идти через подключённый carousel-engine; без запуска engine она не называет результат готовой каруселью.
