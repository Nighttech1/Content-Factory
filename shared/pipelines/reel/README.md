# pipeline: reel — отдел рилсов (Фаза 5)

Вертикальные рилсы (IG/TikTok/YT Shorts). Ведёт **`reel-lead`**; под ним — отдел субагентов. Плагины отдела: **IT Reelsmaker**, **Remotion**, **ffmpeg-llm**; веб-скиллы: `reels-scriptwriter`, `reels-timeline-editor`, `club-reels-module`, `remotion-pipeline`, `heygen-avatar`. Исходники/готовое — Google Drive (`Content Factory/reels/incoming` → `.../output`).

## Отдел (роли и инструмент)
| Роль | Агент | Делает |
|---|---|---|
| 🎬 Лид рилсов | `reel-lead` | владеет пайплайном рилса, координирует отдел, финальная сборка-контроль |
| ✍️ Сценарист рилса | `reel-lead` (скилл `reels-scriptwriter`) | хук 0–2с, биты, VO, on-screen CTA, тайминг 9:16 |
| 🎨 Арт-директор | `art-director` | визуальный стиль, где и какие вставки (мемы/B-roll/графика/субтитр-стиль), QA |
| 🖼 Дизайнер | `designer` | генерит/находит вставки (мемы, B-roll, обложка-кадр), по типу — ген или реал (как в карусели) |
| 🧩 Моушн/графика | Remotion (скилл `remotion-pipeline`) | анимированные титры, подписи, графика по тайм-кодам |
| 🧑‍🎤 Аватар/голос (опц.) | `heygen-avatar` + ElevenLabs | «обезличенные» ролики: говорящая голова + озвучка |
| ✂️ Монтаж | ffmpeg-llm + `reels-timeline-editor` | нарезка, склейка, субтитры (Whisper), мастеринг −14 LUFS, 1080×1920 |
| 🧐 Редактор | `editor` | гейт (хук есть? CTA есть? тон/запреты) |
| 👤 Человек | — | апрув |

## Порядок (chain)
1. **Источник идеи:** контент-план ИЛИ **виральная идея от Разведчика** (агрегаторы sila.app → армянский контекст, см. `scout.md`).
2. **Сценарист рилса** (`reel-lead`+`reels-scriptwriter`) → сценарий: хук 0–2с, биты ценности, VO-текст, **явный CTA** (on-screen/caption).
3. **Арт-директор** → визуальный план: стиль, список вставок (мемы/B-roll/графика) с тайм-кодами (где и сколько), стиль субтитров; выбирает ген vs реал для вставок. → Дизайнеру/Моушн.
4. **Дизайнер/Моушн** → готовят вставки (генерация/поиск реальных/Remotion-графика).
5. **Арт-директор QA** вставок → approve.
6. **Монтаж** (ffmpeg + timeline): исходник из Drive + вставки + субтитры (Whisper) + графика по тайм-кодам → мастеринг −14 LUFS, 1080×1920.
7. **reel-lead** контроль сборки (ритм, хук, читаемость субтитров на мобиле).
8. **Редактор** гейт → **апрув человека** → файл в хранилище, ссылка в `assets/` → публикация (вручную; позже Публикатор).

## Типы рилсов
- **Снятый клубом** (`club-reels`): владелец/участники снимают, ИИ режет + добавляет моушн/субтитры.
- **Обезличенный**: стоковый/генеративный визуал + ElevenLabs-голос (+ HeyGen-аватар).
- **Виральный-адаптация**: формат/хук с агрегатора (Разведчик) переплетён с армянским контекстом.

## Что нужно (ключи/статус)
- `ELEVENLABS_API_KEY` — озвучка (☐ позже). HeyGen — внешний сервис (☐ позже).
- Генерация вставок — `OPENAI_API_KEY`/Ideogram/Flux (☐ Фаза 4).
- ffmpeg/Remotion/Chromium — в контейнере есть; Drive — подключён.

## Гейты
Арт-директор QA · reel-lead сборка · Редактор · Человек. Без хука 0–2с и явного CTA — Редактор заворачивает.
