# pipeline: youtube — отдел YouTube (Фаза 6)

Длинные ролики YouTube (разборы тем встреч, интервью, рекапы, мини-доки) + «обезличенные» каналы. Рилсы/Shorts — НЕ здесь (отдел рилсов).

## Отдел (роли и инструмент)
| Роль | Агент | Делает |
|---|---|---|
| ✍️ Сценарист YouTube | `scriptwriter-youtube` | сценарий (хук→блоки→CTA), заголовок, описание, теги, бриф обложки |
| 🎨 Арт-директор | `art-director` | концепт обложки + визуальный стиль ролика, QA |
| 🖼 Дизайнер + 🖌 Финиш-арт | `designer` + `finish-art-director` | обложка: фон (ген/реал) + текст-крючок и лого HTML-слоем (brand-kit) |
| 🎞 Видео-продюсер | `video-producer` | сборка ролика: отснятое/стоковое/генеративное видео, озвучка, монтаж, субтитры |
| 🧑‍🎤 Аватар/голос (обезличенные) | `heygen-avatar` + ElevenLabs | говорящая голова + озвучка для каналов без лиц |
| 🧐 Редактор | `editor` | гейт (хук, структура, описание/теги, тон/запреты) |
| 👤 Человек | — | апрув |

## Порядок (chain)
1. **Задание** из контент-плана (единица YouTube).
2. **Сценарист YouTube** → сценарий + заголовок (2–3 варианта) + описание + теги + бриф обложки. → `drafts/`.
3. **Арт-директор** → концепт обложки (фон: ген/реал — как в карусели) + визуальный стиль; ставит задачу Дизайнеру.
4. **Дизайнер** фон обложки → **Финиш-арт** кладёт крючок-текст + лого HTML-слоем (brand-kit) → **Арт-дир QA** (CTR-читаемость на мобиле).
5. **Видео-продюсер** собирает ролик: источник (съёмка/сток/генеративный визуал), озвучка (голос/ElevenLabs/HeyGen для обезличенных), монтаж, субтитры (Whisper), тайм-коды.
6. **Редактор** гейт (хук 0–15с, структура, первые строки описания, теги, тон/запреты) → **апрув человека** → ссылка в `assets/` → загрузка (вручную; позже Публикатор через YouTube API).

## «Обезличенный» канал (пайплайн)
Сценарий → стоковый/генеративный визуал + ElevenLabs-озвучка (+ HeyGen-аватар) → монтаж (video-producer) → обложка (ген+бейк) → Редактор → апрув. Без живых лиц.

## Что нужно (ключи/статус)
- `OPENAI_API_KEY`/Ideogram/Flux — обложки/генеративный визуал (☐ Фаза 4).
- `ELEVENLABS_API_KEY` + HeyGen — озвучка/аватар обезличенных (☐ позже).
- `YOUTUBE_API_KEY` — есть (аналитика/загрузка). Remotion/ffmpeg/Whisper/Chromium — в контейнере.

## Гейты
Арт-директор QA обложки · Видео-продюсер сборка · Редактор · Человек.
