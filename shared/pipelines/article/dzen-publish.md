# Дзен — как публикуем (без официального API)

У Дзена нет публичного API публикации. Три пути, от безопасного к рискованному. **Рекомендация: 1 или 2; браузер-скрипт (3) — крайний случай.**

## Путь 1 — Telegram → Дзен (бот Яндекса) ✅ проще всего, без кода
Яндекс даёт бота/связку, которая автоматически переносит посты из **Telegram-канала** в Дзен.
- **Что делает владелец (разово):** в кабинете Дзена привязать наш TG-канал @mosarmclub (Дзен → настройки канала → импорт из Telegram) и пройти модерацию.
- **Дальше автоматически:** постим в TG (ботом, скилл `publisher-telegram`) → Дзен сам забирает. Ноль нашего кода, ноль ключей.
- Минус: формат ограничен постами TG (не полноценный лонгрид-редактор Дзена).

## Путь 2 — RSS-импорт с сайта ✅ для полноценных статей
Дзен умеет тянуть статьи из **RSS-ленты** сайта (единый формат Дзена, не обычный RSS).
- **Что делает команда разработки:** на сайте (или в вебе) отдать RSS-ленту статей в формате Дзена.
- **Что делает владелец (разово):** подключить ленту в кабинете Дзена + модерация (часто доступна после выхода канала на монетизацию).
- **Дальше автоматически:** статья выходит на сайт (по API сайта) → попадает в RSS → Дзен забирает.
- Минус: модерация/условия монетизации.

## Путь 3 — Браузер-скрипт (Playwright) ⚠️ крайний случай
Если 1/2 недоступны — автоматизируем сам веб-редактор Дзена (клики за нас). Chromium/Playwright в контейнере есть. **Это против ToS Дзена, хрупко (меняются селекторы), ловит капчу/2FA — не для частого потока.** Скелет — `scripts/dzen-publish.mjs`.
- **Что нужно от владельца (разово):** один раз залогиниться в Дзен в headful-браузере на VPS и сохранить сессию (cookies/`storageState`) в секретный файл (НЕ в git). Путь к нему — в env `DZEN_STORAGE_STATE`.
- **Как работает:** скрипт грузит сохранённую сессию → открывает редактор → вставляет заголовок/текст/обложку → по умолчанию делает **скриншот (dry-run)**, публикует только с флагом `--publish`.
- Риски: при капче/смене верстки — падает; тогда ручной режим. Логин-сессию не коммитить.

## Пошагово — что делаем сейчас и что требуется от тебя
1. **Я/команда (сделано):** скилл `publisher-telegram` (TG-постинг ботом), скелет `scripts/dzen-publish.mjs`, эта инструкция, план в PLAN «Фаза P».
2. **Ты (разово, когда дойдём):**
   - Дать боту **права админа+постинг** в канале (для TG-постинга).
   - Для Дзена выбрать путь: **(1)** привязать TG-канал в кабинете Дзена (проще) или **(2)** подключить RSS (после готовности ленты).
   - Путь (3) — только если 1/2 не подходят: залогиниться в Дзен на VPS и сохранить сессию.
3. **Следующая сессия (с ключами/доступом):** поднять TG-постинг (`TELEGRAM_BOT_TOKEN`), проверить TG→Дзен / RSS, при необходимости обкатать браузер-скрипт на 1 статье в dry-run.

## VC.ru / Пикабу / Teletype
Публичного write-API нет. Либо так же браузер-скриптом (тот же риск), либо **вручную** с адаптацией под площадку. По умолчанию — вручную; на оригинал (сайт) ставим canonical.
