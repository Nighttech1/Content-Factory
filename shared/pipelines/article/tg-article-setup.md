# Статьи в Telegram (Telegra.ph) — план подключения: кто что делает

Цель: статья с картинками **внутри текста** выходит в TG-канал как **Telegra.ph (Instant View)** — красивая читалка. Бот читает текст статьи из git, картинки грузит в Telegra.ph, постит ссылку в канал. Git держим крошечным (только текст).

## Поток (как будет работать)
```
Сценарист → текст статьи блоками + манифест картинок (в git, килобайты)
   → Арт-директор/Дизайнер → картинки (во внешнее хранилище / готовые к загрузке)
   → Редактор ✅ + апрув человека
   → Публикатор: читает статью из git → грузит картинки в Telegra.ph (хостит сам) → createPage → получает ссылку telegra.ph
   → бот постит ссылку в канал → Instant View (картинки inline)
   → (сайт: отдельно через API сайта; Дзен: через RSS/привязку TG-канала)
```
Картинок в git нет → удалять из git ничего не надо, репо не пухнет.

## Шаги ВЛАДЕЛЬЦА (ты) — что настроить и КАК
1. **Telegraph-токен:** открой в браузере ссылку:
   `https://api.telegra.ph/createAccount?short_name=vernatun&author_name=Вернатун&author_url=https://t.me/mosarmclub`
   В ответе будет JSON — скопируй значение **`access_token`** → положи в окружение как **`TELEGRAPH_ACCESS_TOKEN`**. (Это НЕ BotFather и НЕ бот — отдельный сервис telegra.ph.)
2. **Бот-токен:** положи **`TELEGRAM_BOT_TOKEN`** (твоего существующего бота) в окружение. `TELEGRAM_CHANNEL_ID` — уже в окружении бота, дублировать не надо.
3. **Права бота:** ✅ уже админ канала с правом постинга — ничего делать не надо.
4. **Картинки:** на старте отдельное хранилище НЕ обязательно — Telegra.ph хостит загруженные картинки сам. (Для сайта картинки хостит сайт.)
5. **Дзен (когда захочешь):** разово привяжи TG-канал в кабинете Дзена (Дзен → настройки канала → импорт из Telegram). Токен в окружение не нужен.
6. **Авто-расписание:** выложить веб на VPS (отдельно) — чтобы публикации шли по расписанию без тебя.
