# pipeline: article — статья на сайт (Фаза 7)

Рецепт сборки статьи для сайта Вернатун.

## Шаги
1. **Задание** из `content-plan/ГГГГ-ММ.md` (единица формата «Статья», канал=сайт): тема, CTA, дата.
2. **`scriptwriter-article`** → SEO-заголовок + title-варианты, мета-описание, структура H2/H3, тело (RU + армянские вставки), внутренний CTA в воронку, **брифы на картинки**, перелинковка.
3. **Картинки** → Арт-директор (Фаза 4, когда отдел дизайна готов; нужен ключ генерации, напр. `OPENAI_API_KEY`). Пока — брифы на картинки, без самих изображений.
4. **🧐 Редактор** → вердикт ✅/❌ (тон, запреты, факты, CTA, SEO-структура).
5. **👤 Апрув человека.**
6. **Публикация на сайт** — см. ниже.

## Публикация на сайт — ТЕКУЩАЯ РЕАЛЬНОСТЬ (важно)
Сайт `https://vernatunspeakclub.com/` — **кастомный статический** (nginx/Ubuntu, Tailwind CDN + Alpine.js, `/js/site.js`), **CMS и раздела «статьи/блог» нет**. Поэтому авто-заливки сейчас нет.

**Варианты для владельца (выбрать):**
- **A. Пока вручную** (дефолт): статья готовится в `drafts/`, владелец сам кладёт на сайт. ← сейчас так.
- **B. Добавить раздел «Блог/Статьи»** на статический сайт: генерить HTML-страницу по шаблону сайта (Tailwind) и деплоить на VPS (SSH/rsync/git) — задача команды разработки + доступ к VPS.
- **C. Вести статьи в веб-приложении** (`веб/`, модуль `site-articles`) и отдавать их оттуда — задача команды разработки.

До выбора B/C статьи выходят в черновики (вариант A). Решение владельца — записать сюда и в `env.manifest.md`.

## Распространение (мультиплатформа) — финальная статья улетает в несколько мест
Владелец пришлёт в **окружение API сайта**, по которому финальная статья улетает на `vernatunspeakclub.com`. Дальше тот же материал **дублируется** (кросс-постинг), адаптированный под площадку, со ссылкой назад на сайт/встречи.

| Площадка | Роль в потоке | Примечание |
|---|---|---|
| 🌐 `vernatunspeakclub.com` | **оригинал** (canonical) | по API из окружения (ждём ключ). Пока — вручную |
| 📣 **Яндекс.Дзен** | главный канал дублирования | макс. охват в рунете, аудитория 30+ (наша) |
| 👥 **VK** (статьи + репост в группы «армяне Москвы») | армянская диаспора рунета | диаспора активна в VK |
| 🐾 **Пикабу** | массовый приток | форумный формат, хороший трафик при малых затратах |
| 💬 **VC.ru** | комьюнити/лонгрид | органика урезана (2025), без завышенных ожиданий |
| 📝 **Teletype** | зеркало лонгрида | чистый формат, ссылки |
| *(опц.)* Reddit r/armenia, LiveJournal-сообщества | точечно | по теме |

- **Откуда главный поток:** Дзен (охват) + Пикабу (масса) + VK (диаспора) → на сайт/встречи. VC/Teletype — вторично. **Хабр не берём** (тех-аудитория, не наша).
- **Правило кросс-постинга:** не копипаст — адаптировать заголовок/первый абзац под площадку; на оригинал (сайт) ставить ссылку/canonical, чтобы не каннибализировать SEO.
- Исполняет **Публикатор** (Фаза P); пока владелец раскладывает вручную. Ссылки всех публикаций — в `assets/`.
- Источники по выбору площадок: [checkroi.ru](https://checkroi.ru/blog/gde-vesti-blog/), [workspace.ru](https://workspace.ru/blog/vc-uzhe-vse-3-alternativnye-strategii-stateynogo-marketinga/), [trafficcardinal.com](https://trafficcardinal.com/post/perspektivnye-rossijskie-istochniki-trafika). Эффективность — сверять по своей аналитике (Фаза 9).

## Выход
Черновик статьи в `drafts/ГГГГ-ММ/<ID>-article.md` + вердикт Редактора. Ссылки опубликованных версий (сайт + площадки) — в `assets/`.
