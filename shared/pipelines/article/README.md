# pipeline: article — статья на сайт (Фаза 7)

Рецепт сборки статьи для сайта Вернатун.

## Шаги
1. **Задание** из `content-plan/ГГГГ-ММ.md` (единица формата «Статья», канал=сайт): тема, CTA, дата.
2. **`scriptwriter-article`** → SEO-заголовок + title-варианты, мета-описание, структура H2/H3, тело (RU + армянские вставки), внутренний CTA в воронку, **брифы на картинки**, перелинковка.
3. **Картинки** → Арт-директор (Фаза 4, когда отдел дизайна готов; нужен ключ генерации, напр. `OPENAI_API_KEY`). Пока — брифы на картинки, без самих изображений.
4. **🧐 Редактор** → вердикт ✅/❌ (тон, запреты, факты, CTA, SEO-структура).
5. **👤 Апрув человека.**
6. **Публикация на сайт** — см. ниже.

## Публикация на сайт — ТЕКУЩАЯ РЕАЛЬНОСТЬ (важно)
Сайт `https://vernatunspeakclub.com/` — **кастомный статический** (nginx/Ubuntu, Tailwind CDN + Alpine.js, `/js/site.js`), **CMS и раздела «статьи/блог» нет**. Поэтому авто-заливки сейчас нет.

**Варианты для владельца (выбрать):**
- **A. Пока вручную** (дефолт): статья готовится в `drafts/`, владелец сам кладёт на сайт. ← сейчас так.
- **B. Добавить раздел «Блог/Статьи»** на статический сайт: генерить HTML-страницу по шаблону сайта (Tailwind) и деплоить на VPS (SSH/rsync/git) — задача команды разработки + доступ к VPS.
- **C. Вести статьи в веб-приложении** (`веб/`, модуль `site-articles`) и отдавать их оттуда — задача команды разработки.

До выбора B/C статьи выходят в черновики (вариант A). Решение владельца — записать сюда и в `env.manifest.md`.

## Выход
Черновик статьи в `drafts/ГГГГ-ММ/<ID>-article.md` + вердикт Редактора. Ссылка на опубликованную версию — в `assets/` после публикации.
