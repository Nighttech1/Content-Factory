# Пайплайн: Рилсы (reels)

Единое место для всего по рилсам: формат-пресеты + рабочие доки конкретных роликов.
(Раньше было разбросано по `projects/vernatun/{reel-types,drafts,assets}` — свели сюда.)

## Содержимое
- `type-1-pov-meme.md` — **Рилс Тип №1** (POV-мем / контраст-панчлайн): утверждённый формат-шаблон.
- `reel-01.md` — манифест Рилса №1 (исходники, тайминг, тех.параметры, статус).
- `reel-01-caption.md` — тексты Рилса №1 (подпись, первый коммент, хэштеги).

## Правила
- Полные правила оформления — у агента: `projects/vernatun/.claude/agents/reel-lead.md` (раздел «Стандарты оформления»). В `.claude` держим ТОЛЬКО конфиг агентов (правила/скиллы/коннекторы).
- Пайплайны/типы/рабочие доки — здесь, в `shared/pipelines/`.
- Когда рилсы появятся во втором проекте (fingrad) — разложим по подпапкам проекта (`reels/<проект>/...`), чтобы не смешивать (см. CLAUDE.md).
