# pipeline: image — отдел изображений Вернатуна

Отдел производит одиночные визуальные материалы клуба: Telegram-постеры, анонсы встреч, карточки с цитатами, культурные иллюстрации и обложки. Пайплайн адаптирован из карусельного layered-html подхода.

## Принцип

Фон создаётся отдельно от бренд-контента. Текст по запросу владельца генерируется внутри самого изображения. HTML/CSS/SVG-слой используется только для настоящего логотипа из веба; выдуманные логотипы запрещены.

## Chain

1. Клиент / image-lead: ID, цель, канал, формат, точный текст, CTA.
2. Арт-директор: концепция, композиция, safe-zone и визуальные критерии.
3. Дизайнер изображений: чистый фон без букв, логотипов и водяных знаков.
4. Финиш-арт: HTML/CSS/SVG-композит с логотипом и текстом.
5. Арт-директор QA: проверка итогового PNG на полном размере и на телефоне.
6. Редактор: тон, факты, CTA и запреты.
7. Владелец: явный апрув; публикация отдельно.

## Типы

- A — генеративный фон + HTML-бейк.
- B — full HTML для расписаний, чеклистов и инфопостеров.
- C — реальное фото клуба или владельца с отдельным HTML-слоем.
- D — культурная иллюстрация без букв и брендинга.
- E — обложка или превью в утверждённом размере.

## Контракт типографики

Все модули изображений читают типографику из `projects/vernatun/brand/design.md`.
Главный шрифт: **Noto Serif Display Black 900**; asset:
`shared/brand/fonts/NotoSerifDisplay[wdth,wght].ttf`. Заголовки, hook и CTA
рендерятся весом `900`; отсутствие asset возвращает `FONT_PRIMARY_MISSING`.
Montserrat не используется как замена главного шрифта.

## Контракт финиш-арта

На входе: размер, фон, safe-zone, точный текст, размер и место логотипа, цвета текста, CTA и имя финального PNG.

На выходе: PNG точного размера, HTML/CSS/SVG-исходник, манифест с бренд-токенами и отметка QA арт-директора.

Без design.md нельзя выдумывать стиль. Без визуального просмотра итогового PNG нельзя писать «QA пройден». Публикация невозможна без редакторского ✅ и апрува владельца.

Тяжёлые изображения хранятся во внешней библиотеке; в Git попадают инструкции, брифы, статусы и манифесты.
