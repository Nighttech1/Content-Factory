# Text-first composition rule

Фон карусели нельзя принимать только как красивую самостоятельную картинку. Финальный макет учитывается до генерации.

## Персонаж

В пайплайне не существует одной постоянной «героини Vernatun». Для каждой задачи клиент передаёт конкретный референс или указывает персонажа из папки персонажей. Промпт обязан ссылаться на переданный reference image и сохранять именно его идентичность.

## Hook и CTA

Hook и CTA — исключение из обычного HTML-бейка: их текст генерируется непосредственно внутри изображения как крупная AI-типографика.

Для hook и CTA не нужно задавать отдельную пустую геометрическую текстовую зону, координаты или искусственную «стену без деталей». Нужно описать общую красивую композицию и сам текст; модель самостоятельно балансирует типографику, персонажа и среду.

Арт-директор после генерации проверяет: текст читается, выглядит крупно и выразительно, не закрывает лицо/главный жест, не выглядит случайной надписью и побуждает к действию. Если нет — изображение отклоняется.

## Слайды с HTML-карточками

Для промежуточных словарных слайдов фон генерируется без текста и должен заранее учитывать реальные границы трёх будущих карточек. Здесь обязательно задаются точные зоны персонажей, ключевого действия и карточек.

Карточки не могут закрывать лицо, руки, взаимодействие или главный предмет сцены.

## Общая проверка

Внутри одной карусели нельзя повторять композицию. Нет квот по сольным, диалоговым или групповым сценам; арт-директор выбирает их по сценарию.

Арт-директор принимает фон только после проверки будущего финального макета.
