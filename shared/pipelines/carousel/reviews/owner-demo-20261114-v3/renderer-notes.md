# Chromium и замена рендера

Chromium — браузер, который рисует HTML/CSS в пиксели. Playwright управляет браузером: ждёт шрифты/картинки, проверяет DOM и делает PNG. Поэтому Chromium нужен и для экспорта, и для части проверок, а не является названием проверки.

Cairo/Pango уже собрал этот статичный набор без браузера: Cairo рисует слои, Pango формирует текст. Для статичных PNG возможен отдельный производственный маршрут с проверкой фактических шрифтов и глифов, размеров/границ, контраста, хешей, повторной сборки и обязательным визуальным QA. Он не проверяет HTML, поэтому нельзя просто заменить Playwright на Cairo внутри прежнего отчёта.

Сейчас такой маршрут в Git помечен preview. Альтернативы: выполнять существующий Chromium runner в подходящем окружении (например, вручную на компьютере или CI после настройки), либо отдельно утвердить и реализовать производственный Cairo-маршрут. Смена на Firefox/WebKit тоже требует адаптации и проверки, не гарантирует запуск в этом окружении.

Текущий пакет: визуальная проверка PNG пройдена, Chromium gate заблокирован. Политика автоматически не переписана.
