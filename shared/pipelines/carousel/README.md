# pipeline: carousel — отдел каруселей Вернатуна

Карусель собирается по ручной эстафете. Производство не начинается без ID, утверждённого сценария, референсов и заполненного брифа.

## Классы

- **Привлечение:** AI-фон + AI-типографический hook/final + HTML/CSS/SVG для точных информационных блоков.
- **Полезная:** AI-фон + HTML/CSS/SVG-бейк; весь фактический текст управляемый.
- **Словарь:** AI-hook и AI-final в утверждённом стиле; слайды со словарём — только HTML/CSS/SVG-бейк, ровно 3 фразы на слайд.
- **Интерактивная:** только motion HTML/CSS/SVG/JS, без генеративного фона.

## Жёсткие правила визуала

- Canvas 1080×1350, safe-zone 7–8%.
- Референс логотипа — единственный источник логотипа. Логотип не перерисовывается и не генерируется заново.
- Логотип размещается справа сверху с тем же визуальным отступом, что в утверждённом референсе.
- Фон не содержит случайных букв, псевдотекста, лишних логотипов или UI.
- Для hook/final AI-типографики текст, композиция, шрифтоподобный стиль и логотип проверяются на самом изображении. HTML не подменяет этот слой.
- Для middle-слайдов факты, переводы, карточки, CTA и логотип — управляемый HTML/CSS/SVG-слой.
- Century Gothic — основной брендовый шрифт; Noto Sans Armenian — армянский. Fallback фиксируется в манифесте.

## Обязательная цепочка

1. **Сценарист:** готовит 00-brief и 10-script.
2. **Арт-директор — сценарий:** проверяет hook, обещание, последовательность, количество фраз и CTA. Возвращает сценарий на доработку при любом нарушении.
3. **Арт-директор — промпт:** готовит visual-system и точные background prompts. Для hook/final отдельно описывает AI-типографику и референс логотипа.
4. **Генерация фона/AI-art:** запускается только после принятия промпта.
5. **Арт-директор — приём фона:** проверяет композицию, позу, стиль, читаемую зону, отсутствие мусорного текста и правильный логотип. Статус только `ACCEPTED` или `REGENERATE`. При `REGENERATE` bake запрещён.
6. **Bake:** получает только принятые кадры и bake-task. Накладывает HTML/CSS/SVG: фразы, переводы, карточки, точный логотип, CTA.
7. **Арт-директор — финальный приём bake:** проверяет совмещение фона и слоя, safe-zone, читаемость, иерархию, соответствие референсу и отсутствие дублей логотипа. Статус только `ACCEPTED` или `RETURN`.
8. **QA/редактор:** проверяет технический экспорт и выдаёт `✅`/ `❌`.
9. **Клиент:** принимает карусель отдельным явным сообщением. До этого публикация запрещена.

## Стоп-критерии арт-директора

Немедленный возврат на доработку при: неверном логотипе или позиции; AI-псевдотексте; расхождении фона и bake; выходе текста за safe-zone; лишнем тексте; нарушении числа фраз; слабом контрасте; неправильной героине/позе; несоответствии референсу.

## Артефакты

`00-brief.md` → `10-script.md` → `20-art-direction/visual-system.md` + `background-prompts.md` + `bake-task.md` → `30-design-manifest.md` → `40-bake-manifest.md` → `50-art-qa.md` → `60-editor-verdict.md`.

В каждом manifest обязательны: статус, причина принятия/возврата, версия промпта, asset ID, размер, шрифт, logo source и следующий шаг.
