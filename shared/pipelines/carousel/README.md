# pipeline: carousel — отдел каруселей Вернатуна

Карусель собирается по ручной эстафете. Производство не начинается без ID, утверждённого сценария, референсов и заполненного брифа.

## Классы

- **Привлечение:** AI-фон + крупная AI-типографика hook/final + HTML/CSS/SVG для точных информационных блоков.
- **Полезная:** AI-фон + HTML/CSS/SVG-бейк; весь фактический текст управляемый.
- **Словарь:** AI-hook и AI-final в утверждённом стиле; слайды со словарём — только HTML/CSS/SVG-бейк, ровно 3 фразы на слайд.
- **Интерактивная:** только motion HTML/CSS/SVG/JS, без генеративного фона.

## Жёсткие правила визуала

- Canvas 1080×1350, safe-zone 7–8%.
- Финальная композиция планируется до сценария генерации: фокус, путь чтения, поза героини, текстовый объём, плотность, логотип и контраст.
- Фон определяется сценарием: магазин, улица, кафе, встреча, выставка, городской клуб и т. д. Арт-директор не навязывает один тип локации. Запрещены только неуместные classroom/whiteboard/lecture-сцены, если их нет в сценарии.
- Приложенная картинка-референс используется только как источник вырезки логотипа. Её сцена, люди, текст и композиция не копируются в фон.
- Логотип не перерисовывается и не генерируется. Позиция строго фиксирована: справа сверху, одинаковые X/Y-отступы в safe-zone 7–8%.
- В каждом кадре используется канонический asset или его чёрная/белая контрастная производная; качество обтравки wordmark проверяется отдельно.
- Референсы героини обязательны: героиня должна присутствовать в каждом AI-фоне.
- Поза не выбирается из заранее заготовленного списка. Каждый фон генерирует новую сюжетную позу. После генерации фиксируется фактический pose fingerprint (ракурс, силуэт, жест, gaze), и близкие повторы запрещаются.
- AI-фон не содержит логотипов, случайных букв, псевдотекста, UI, карточек, панелей и подложек под будущий bake.
- В prompt заранее указывается top-right logo safe-zone: спокойный однотонный участок без смены цвета/контрастных деталей, но без нарисованной плашки.
- Hook/final AI-типографика должна быть крупной и заметной в Instagram-ленте: минимум 25–30% визуальной высоты композиции, с ясной иерархией.
- Для middle-слайдов фразы, переводы, карточки, CTA и логотип — управляемый HTML/CSS/SVG-слой.
- Плашки словаря: полупрозрачный terracotta `#C95B36`, белый текст, opacity 0.78–0.88. Контраст проверяется на полном размере.
- Текстовая карточка компактна и определяется текстом. Не допускается плашка, визуально в 1.5 раза превышающая содержимое без документированной причины.
- Нельзя вкладывать одну плашку в другую. Один текстовый блок = один контейнер.
- Плашки и текст не перекрывают лицо, руки или главный жест героини.
- Главный шрифт: `shared/brand/fonts/NotoSerifDisplay[wdth,wght].ttf`, Noto Serif Display Black 900. Montserrat — только utility sans; Noto Sans Armenian — армянский текст. Silent fallback запрещён.

## Обязательная цепочка

1. **Сценарист:** готовит 00-brief и 10-script.
2. **Архитектор + арт-директор — композиция:** сначала собирают карту финальных слайдов: текст, герой, поза, фокус, плотность, логотип и читаемость.
3. **Арт-директор — сценарий:** проверяет hook, обещание, последовательность, количество фраз и CTA. Возвращает сценарий на доработку при любом нарушении.
4. **Арт-директор — промпт:** пишет prompt из утверждённой композиции, современных сцен и pose registry.
5. **Генерация фона/AI-art:** запускается только после принятия промпта.
6. **Арт-директор — приём фона:** проверяет героиню, уникальность позы, современность сцены, композицию, плотность, отсутствие случайной пустоты, логотипа, карт и псевдотекста. Статус только `ACCEPTED` или `REGENERATE`.
7. **Bake:** получает только принятые кадры и покадровый bake-task с координатами x/y/w/h для каждой карточки, текстового блока, стрелки и логотипа. Накладывает компактные terracotta-плашки, фразы, переводы и контрастный логотип.
8. **Арт-директор — финальный приём bake:** проверяет совмещение фона и слоёв, плашки не закрывают героиню, нет вложенных блоков, карточки компактны, hook/final крупны, логотип чистый и читаемый. Статус только `ACCEPTED` или `RETURN`.
9. **QA/редактор:** проверяет технический экспорт и выдаёт `✅`/`❌`.
10. **Внутренний клиент-дизайнер:** смотрит contact sheet и каждый слайд отдельно по чек-листу. Статус только `CLIENT_DESIGN_ACCEPTED` или `RETURN_TO_FIXER`.
11. **Внешний клиент:** получает только результат со статусом `CLIENT_DESIGN_ACCEPTED` и отдельно принимает или возвращает карусель. До этого публикация запрещена.

## Стоп-критерии

Немедленный возврат при: повторе позы; плашке на героине; вложенных блоках; карточке, непропорционально большой тексту; случайной пустой зоне; маленьком hook/final; коврово-этническом шаблонном фоне; системном шрифте вместо брендового или repo fallback; нечитаемом/рваном логотипе; неправильном X/Y логотипа; слабом контрасте; отсутствии героини; неверной позе; использовании референсной картинки целиком; сгенерированном логотипе; AI-псевдотексте; расхождении фона и bake; выходе текста за safe-zone; нарушении числа фраз.

## Артефакты

`00-brief.md` → `10-script.md` → `20-art-direction/visual-system.md` + `background-prompts.md` + `bake-task.md` → `30-design-manifest.md` → `40-bake-manifest.md` → `50-art-qa.md` → `60-editor-verdict.md`.

В каждом manifest обязательны: статус, причина принятия/возврата, версия промпта, heroine reference/pose, pose registry, logo source/contrast variant, asset ID, размер, шрифт и следующий шаг.
