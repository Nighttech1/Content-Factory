# pipeline: carousel — отдел каруселей Вернатуна

Карусель собирается по ручной эстафете. Производство не начинается без ID, утверждённого сценария, референсов и заполненного брифа.

## Классы

- **Привлечение:** AI-фон + AI-типографический hook/final + HTML/CSS/SVG для точных информационных блоков.
- **Полезная:** AI-фон + HTML/CSS/SVG-бейк; весь фактический текст управляемый.
- **Словарь:** AI-hook и AI-final в утверждённом стиле; слайды со словарём — только HTML/CSS/SVG-бейк, ровно 3 фразы на слайд.
- **Интерактивная:** только motion HTML/CSS/SVG/JS, без генеративного фона.

## Жёсткие правила визуала

- Canvas 1080×1350, safe-zone 7–8%.
- Финальная композиция планируется до сценария генерации: фокус, путь чтения, поза героини, текстовый объём, плотность, логотип и контраст.
- Приложенная картинка-референс используется только как источник вырезки логотипа. Её сцена, люди, текст и композиция не копируются в фон.
- Логотип не перерисовывается и не генерируется. В каждом кадре используется один канонический asset или его утверждённая чёрная/белая контрастная производная, справа сверху, с отступами из референса.
- Референсы героини обязательны: героиня должна присутствовать в каждом AI-фоне, а выбранная поза и reference asset фиксируются в manifest.
- Pose registry обязателен: одинаковая поза, камера и главный жест не повторяются внутри одной карусели; повтор в следующих заданиях допускается только с причиной.
- AI-фон не содержит логотипов, случайных букв, псевдотекста, UI, карточек, панелей и подложек под будущий bake.
- Для hook/final AI-типографика допускается только как часть заранее спроектированного AI-art; свободная пустая половина кадра без композиционной функции = REGENERATE.
- Для middle-слайдов фразы, переводы, карточки, CTA и логотип — управляемый HTML/CSS/SVG-слой.
- Текстовая карточка компактна и определяется текстом. Не допускается плашка, визуально в 1.5 раза превышающая содержимое без документированной причины.
- Нельзя вкладывать одну плашку в другую. Один текстовый блок = один контейнер.
- Плашки и текст не перекрывают лицо, руки или главный жест героини.
- Century Gothic — основной шрифт для русского и латиницы; Noto Sans Armenian — армянский. Системный шрифт не может быть primary. Fallback фиксируется в манифесте.

## Обязательная цепочка

1. **Сценарист:** готовит 00-brief и 10-script.
2. **Архитектор + арт-директор — композиция:** сначала собирают карту финальных слайдов: текст, герой, поза, фокус, плотность, логотип и читаемость.
3. **Арт-директор — сценарий:** проверяет hook, обещание, последовательность, количество фраз и CTA. Возвращает сценарий на доработку при любом нарушении.
4. **Арт-директор — промпт:** пишет prompt из утверждённой композиции, а не из абстрактной свободной зоны.
5. **Генерация фона/AI-art:** запускается только после принятия промпта.
6. **Арт-директор — приём фона:** проверяет героиню, уникальность позы, композицию, плотность, отсутствие случайной пустоты, логотипа, карт и псевдотекста. Статус только `ACCEPTED` или `REGENERATE`.
7. **Bake:** получает только принятые кадры и bake-task. Накладывает один слой карточек, фразы, переводы и контрастный логотип.
8. **Арт-директор — финальный приём bake:** проверяет совмещение фона и слоёв, плашки не закрывают героиню, нет вложенных блоков, карточки компактны, логотип читаем. Статус только `ACCEPTED` или `RETURN`.
9. **QA/редактор:** проверяет технический экспорт и выдаёт `✅`/`❌`.
10. **Внутренний клиент-дизайнер:** смотрит contact sheet и каждый слайд отдельно по чек-листу. Статус только `CLIENT_DESIGN_ACCEPTED` или `RETURN_TO_FIXER`.
11. **Внешний клиент:** получает только результат со статусом `CLIENT_DESIGN_ACCEPTED` и отдельно принимает или возвращает карусель. До этого публикация запрещена.

## Стоп-критерии

Немедленный возврат при: повторе позы; плашке на героине; вложенных блоках; карточке, непропорционально большой тексту; случайной пустой зоне; системном шрифте вместо брендового; нечитаемом логотипе; отсутствии героини; неверной позе; использовании референсной картинки целиком; сгенерированном/заменённом логотипе; неверной позиции логотипа; AI-псевдотексте; расхождении фона и bake; выходе текста за safe-zone; лишнем тексте; нарушении числа фраз; слабом контрасте.

## Артефакты

`00-brief.md` → `10-script.md` → `20-art-direction/visual-system.md` + `background-prompts.md` + `bake-task.md` → `30-design-manifest.md` → `40-bake-manifest.md` → `50-art-qa.md` → `60-editor-verdict.md`.

В каждом manifest обязательны: статус, причина принятия/возврата, версия промпта, heroine reference/pose, pose registry, logo source/contrast variant, asset ID, размер, шрифт и следующий шаг.
