# pipeline: carousel — отдел каруселей Вернатуна

Карусель собирается по ручной эстафете. Производство не начинается без ID, утверждённого сценария, референсов и заполненного брифа.

## Классы

- **Привлечение:** AI-фон + AI-типографический hook/final + HTML/CSS/SVG для точных информационных блоков.
- **Полезная:** AI-фон + HTML/CSS/SVG-бейк; весь фактический текст управляемый.
- **Словарь:** AI-hook и AI-final в утверждённом стиле; слайды со словарём — только HTML/CSS/SVG-бейк, ровно 3 фразы на слайд.
- **Интерактивная:** только motion HTML/CSS/SVG/JS, без генеративного фона.

## Жёсткие правила визуала

- Canvas 1080×1350, safe-zone 7–8%.
- Приложенная картинка-референс используется **только как источник вырезки логотипа**. Её сцена, люди, текст и композиция не копируются в фон.
- Логотип не перерисовывается и не генерируется. В каждом кадре используется один и тот же вырезанный asset логотипа, справа сверху, с отступами из референса.
- Референсы героини обязательны: героиня должна присутствовать в каждом AI-фоне, а выбранная поза и reference asset фиксируются в manifest.
- AI-фон не содержит логотипов, случайных букв, псевдотекста или UI.
- Для hook/final AI-типографика допускается только как часть сгенерированного AI-art; точный логотип поверх неё всегда добавляется из вырезанного asset HTML/SVG-слоем.
- Для middle-слайдов фразы, переводы, карточки, CTA и логотип — управляемый HTML/CSS/SVG-слой.
- Century Gothic — основной брендовый шрифт; Noto Sans Armenian — армянский. Fallback фиксируется в манифесте.

## Обязательная цепочка

1. **Сценарист:** готовит 00-brief и 10-script.
2. **Арт-директор — сценарий:** проверяет hook, обещание, последовательность, количество фраз и CTA. Возвращает сценарий на доработку при любом нарушении.
3. **Арт-директор — промпт:** готовит visual-system и точные background prompts, включая reference героини, позу, свободную зону под HTML и запрет логотипа/псевдотекста.
4. **Генерация фона/AI-art:** запускается только после принятия промпта.
5. **Арт-директор — приём фона:** проверяет наличие героини, выбранную позу, композицию, свободную зону, стиль и отсутствие логотипа/мусорного текста. Статус только `ACCEPTED` или `REGENERATE`. При `REGENERATE` bake запрещён.
6. **Bake:** получает только принятые кадры и bake-task. Накладывает вырезанный логотип, фразы, переводы, карточки и CTA.
7. **Арт-директор — финальный приём bake:** проверяет совмещение фона и слоёв, логотип справа сверху, safe-zone, читаемость, иерархию, героиню и отсутствие дублей логотипа. Статус только `ACCEPTED` или `RETURN`.
8. **QA/редактор:** проверяет технический экспорт и выдаёт `✅`/ `❌`.
9. **Внутренний клиент-дизайнер:** выполняет обязательную финальную визуальную приёмку: смотрит contact sheet и каждый слайд отдельно, оценивает композицию, типографику, баланс, safe-zone, героиню, логотип и соответствие бренду. Статус только `CLIENT_DESIGN_ACCEPTED` или `RETURN_TO_FIXER`.
10. **Внешний клиент:** получает только результат со статусом `CLIENT_DESIGN_ACCEPTED` и отдельно принимает или возвращает карусель. До этого публикация запрещена.

## Стоп-критерии

Немедленный возврат при: отсутствии героини; неверной позе; использовании референсной картинки целиком; сгенерированном/заменённом логотипе; неверной позиции логотипа; AI-псевдотексте; расхождении фона и bake; выходе текста за safe-zone; лишнем тексте; нарушении числа фраз; слабом контрасте; несоответствии референсу.

## Артефакты

`00-brief.md` → `10-script.md` → `20-art-direction/visual-system.md` + `background-prompts.md` + `bake-task.md` → `30-design-manifest.md` → `40-bake-manifest.md` → `50-art-qa.md` → `60-editor-verdict.md`.

В каждом manifest обязательны: статус, причина принятия/возврата, версия промпта, heroine reference/pose, logo source, asset ID, размер, шрифт и следующий шаг.
