# Карусели: образец-карусель + метрики от Scout

## 1. Карусель-образец («сделай так же»)
Владелец кидает агенту каруселей понравившуюся карусель (стиль, расположение
текста, шрифт) и просит сделать такую же нашу. Эта присланная карусель должна
оказаться в колонке **«Конкуренты» ПЕРВОЙ строкой** (выше находок Разведчика).

**Контракт (агент → веб):**
```
POST {CONTENT_FACTORY_WEB_URL}/api/content/reference   (x-ingest-secret: INGEST_SECRET)
{
  "id": "ref-user-001",            // стабильный id (идемпотентно)
  "title": "Образец: минимал, крупный шрифт по центру",
  "thumbUrl": "https://.../ref.jpg", // превью образца (ссылка)
  "username": "образец",            // метка-подпись на плашке
  "note": "крупный шрифт, текст по центру, тёплый фон"  // что скопировать
}
```
Веб кладёт образец в стор `data/local/carousel-references.json` и показывает его
**первым** в «Конкуренты» на экране `carousel-engine` (помечен `isReference`,
подпись `образец`). Затем идут конкуренты из снапшота Scout.

**Поток:** владелец → агент каруселей (облачный чат) → агент берёт стиль образца
для нашей карусели И пушит сам образец в веб (`/api/content/reference`) → образец
виден первой строкой как ориентир. Готовую нашу карусель агент присылает как
обычную единицу (`/api/content/ingest`, type `carousel`) после апрува.

## 2. Метрики каруселей — от Scout (подтверждено)
Колонка «Конкуренты» на экране Карусели берёт посты и **показатели (лайки,
просмотры, охваты)** из **последнего снапшота Scout** (`getScoutCompetitorsForFeed`),
а НЕ из Apify напрямую (Apify — только по кнопке «Разведать»/расписанию у Scout).
То есть все цифры по каруселям приходят с нашего Разведчика (scraper). Свои
(«Наши») — из IG Graph, когда подключён, иначе пусто.

> Итого: образцы владельца → первыми в конкурентах; остальные конкуренты и их
> метрики → от Scout. Веб только отображает.
