## Метод

1. Определить период/часовой пояс, сравниваемую выборку, каналы и источник
   каждого показателя. Применять готовые разрешённые данные; сбор заново
   и расход кредитов требуют отдельного задания владельца.
2. Для каждой метрики указать определение, единицы, знаменатель, текущий период,
   сопоставимый прошлый период, цель/основание и ограничение. Отсутствующее
   значение — неизвестно, не 0. При нулевой базе относительный рост не считать.
3. Связать данные с воронкой: контент → Telegram → встреча → возврат. Не выводить
   регистрацию или явку из лайков/просмотров без отдельного учёта.
4. Разделить наблюдение, возможные объяснения и действие. Вирусный пример не
   доказывает причину успеха. Чужие отраслевые benchmarks не становятся целью.
5. Для предложенного эксперимента определить один фактор, основную метрику,
   ограничения, baseline и правило оценки заранее. Без достаточной выборки и
   корректного распределения результат описывать как наблюдение/неопределённость,
   не как статистически доказанную победу. Не запускать A/B по одной инструкции.
6. Дать 3–5 практических выводов директору: данные/источник → интерпретация →
   предлагаемое изменение → ожидаемый сигнал → усилия/ограничения.

## Выход и gate

Отчёт директору в существующем analyst-контуре. План меняет директор, не аналитик.
Публичный scraping не раскрывает saves/reach/shares/демографию, чужой CTR или
retention; для них нужен отдельный достоверный источник. Прогноз маркируется
сценарием с предпосылками, не подменяет измерение фактического результата.

## Уточнение lifecycle · 09.11.2026

Применить `projects/vernatun/brand/growth-marketing-playbook.md`, разделы 4–6. Проверять весь путь cold attraction → интерес → регистрация → первый визит → возврат → членство и ветки рекомендаций/реактивации. value=null не ноль; сравнимые единица/период/когорта обязательны; знаменатель 0/null означает отсутствие процента. Возврат за 30 дней только после календарной зрелости; у реактивации собственная dormant-база, у рекомендаций — подходящий опыт, не соседняя карточка. Намерения не revenue, gross не прибыль, CAC при 0 ₽ продвижения не автоматически нулевой. Для стратегии вернуть узкое место, возможное объяснение, контрсигнал и один тест с правилом решения; не заменять отсутствие данных отраслевым benchmark.
