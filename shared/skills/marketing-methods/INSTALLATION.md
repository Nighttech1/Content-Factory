В каждом из 17 профилей есть явный обязательный путь: общий SKILL.md → свой
модуль → существующий выход этапа/gate. В shared/pipelines обновлены четыре
README форматов; дополнительные точки входа — README отделов scout и director.
Ссылки также встроены в пять имеющихся навыков: scout-evidence,
content-director-growth, carousel-storycraft, reel-motion-design,
reel-department-runner. Машиночитаемая карта — [routing.json](routing.json).

## Как это работает в следующем задании

Достаточно обычного обращения к роли и ID/теме по правилам её пайплайна.
Её профиль указывает прочитать общий адаптер и назначенный модуль. Не нужно
называть отсутствующую slash-команду или устанавливать Marketing нативно.

Скаут готовит `S-…` и адресные рекомендации, директор создаёт производственное
задание, отдел проходит свои этапы. Для рилсов сохранены режимы A/B, этапы
отдельных специалистов, lead ACCEPT и максимум исправлений по действующему
reel-department-runner. Этот импорт не создаёт новые content jobs и не разрешает
публикацию, опросы участников, платные API или генерацию медиа.
