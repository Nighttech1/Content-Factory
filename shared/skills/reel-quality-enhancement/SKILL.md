# Улучшение качества рилсов

Исполнитель — reel-finisher, приёмка — reel-lead и editor. Вход: ID, доступный
оригинал и права. Готовый монтаж можно улучшать без пересоздания сценария.
Без файла и просмотра нельзя объявлять улучшенный рилс готовым.

## Навыки и инструменты

- Облачные навыки FFmpeg: ffmpeg-onboarding, ffmpeg-environment (проверка среды),
  ffmpeg-workflow, ffmpeg-video-editing (restore/upscale), ffmpeg-diagnostics
  (ошибки декодирования/тайминга), ffmpeg-audio (при проблемах звука).
- FFmpeg Media Toolkit: doctor, video upscale; установку и версию проверять
  заново в текущей среде. Наличие инструкции не означает наличие CLI.
- FFprobe: ориентация/SAR, размер, fps/VFR, кодеки, цвет/HDR, звук, длительность.
- FFmpeg: масштабирование Lanczos/zscale; при выявленном дефекте — hqdn3d/nlmeans,
  deblock/deband, мягкий unsharp. Проверять доступность фильтров. Не применять
  все фильтры автоматически. Нативный FFmpeg — для операций вне typed toolkit.
- Remotion: свои титры/лого лучше повторно рендерить в целевом размере, если
  доступны проект и runtime. Не считать их доступными без проверки.
- AI: Real-ESRGAN (официальный https://github.com/xinntao/Real-ESRGAN) — кандидат
  для короткой пробы, не установленная по умолчанию модель. Проверять лицензии,
  зависимости/веса, память, GPU и временную стабильность. Не включать генеративное
  восстановление лиц по умолчанию. Runway — опциональный внешний апскейл;
  требует фактического подключения и проверки операции, цены и разрешения.

## Google Colab и бюджет

Проверено по официальным источникам 2026-11-07:
https://research.google.com/colaboratory/faq.html
https://docs.cloud.google.com/free/docs/free-cloud-features

- Бесплатный Colab: GPU по доступности, квоты меняются и не публикуются;
  до 12 часов — верхний предел сессии, не гарантированное время GPU.
- Работать интерактивно в ноутбуке. Не превращать бесплатный runtime в удалённый
  API/SSH-сервер, не обходить лимиты. Для апскейла используем готовую модель,
  обучение с нуля не нужно. Запуск начинается с пробы 3–5 секунд.
- Google Cloud Free Trial: заявлено $300 на 90 дней для подходящих новых
  пользователей, нужен способ оплаты; GPU в VM недоступен до перехода на Paid.
  Это не маршрут с гарантированным нулевым расходом для апскейла.
- Вход в Google в другом приложении не даёт этому чату OAuth/Cloud-доступ.
  Проверять bindings/коннекторы и браузерные инструменты. Не извлекать cookies,
  пароли или токены. Если нужен вход, владелец выполняет его через штатный UI.
- При запросе бесплатного варианта не активировать платный billing, подписки
  и платные API. Не переключаться на платный путь при исчерпании квоты.

## Обработка и приёмка

1. Проверить и просмотреть исходник; определить, что реально требует исправления.
2. Записать метод/параметры и тестовые диапазоны в 30-edit-plan.md.
3. Сравнить короткую пробу с исходником при одинаковом размере, в том числе
   движение, лица, мелкие буквы. Масштабирование не доказывает рост качества.
4. Применить выбранный метод при видимом выигрыше; иначе SKIP с причиной.
   Сохранить монтаж/fps/звук, не растягивать кадр. HDR преобразовывать корректно,
   не простой заменой метаданных. Не добавлять интерполяцию кадров по умолчанию.
5. Рабочий профиль Instagram: 1080×1920, 9:16, MP4 H.264/yuv420p, AAC при наличии
   аудио, faststart. Параметры цвета/fps выбирать по исходнику; это ориентир
   отдела, не гарантия отсутствия сжатия площадкой. 4K не нужен по умолчанию.
6. Проверить декодирование всего файла, FFprobe и воспроизведение экспорта
   со звуком: мерцание, ореолы, кожа, текст, цвет, стыки, CTA, синхронизация.
7. В 40-output-manifest.md записать до/после, инструменты/версии/модель,
   параметры, фактический просмотр и ограничения. Повторить затронутые editor
   gates. Выдать файл только после QA; не публиковать.

Исходник не перезаписывать. Медиа вне Git, временное в work/, выдача в разрешённом
output/хранилище. Наличие GPU в списке FFmpeg не доказывает рабочее устройство.
