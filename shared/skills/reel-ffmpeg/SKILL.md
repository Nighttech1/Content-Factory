# Скилл: FFmpeg для рилсов

Используй после того, как начальник рилсов заполнил `30-edit-plan.md`. FFmpeg —
исполнитель монтажа, не сценарист и не арт-директор: он не выбирает кадры и не
меняет утверждённый текст.

## Предстартовая проверка

```bash
ffmpeg -version
ffprobe -v error -show_entries format=duration -of default=nw=1 INPUT.mp4
```

- [ ] В `departments/reel/jobs/<ID>/10-script.md` есть хук, биты и CTA.
- [ ] В `20-art-direction.md` есть текст субтитров и разрешённые вставки.
- [ ] В `30-edit-plan.md` есть ссылки на каждый исходник и тайм-коды.
- [ ] Проверены права на музыку, видео и изображения.
- [ ] Выходной путь находится во внешнем хранилище или локальной папке сборки, не в Git.

## Базовый экспорт

Для уже собранного входа используй явный выходной файл и не перезаписывай его без
решения владельца:

```bash
ffmpeg -n -i INPUT.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2,format=yuv420p" \
  -c:v libx264 -crf 18 -preset medium -movflags +faststart \
  -c:a aac -b:a 192k OUTPUT.mp4
```

Для громкости речи сначала измерь, затем применяй параметры из измерения; не
нормализуй «на глаз». Субтитры и бренд-слой добавляй только из утверждённого
монтажного листа и `design.md`.

## Проверка результата

```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream=width,height,codec_name -of default=nw=1 OUTPUT.mp4
ffprobe -v error -show_entries format=duration -of default=nw=1 OUTPUT.mp4
```

- [ ] Разрешение `1080×1920`, видео H.264, аудио AAC.
- [ ] Хук считывается в первые две секунды.
- [ ] Субтитры читаемы на мобильном и не выходят за safe-zone.
- [ ] Логотип и CTA соответствуют утверждённому визуальному плану.
- [ ] Ссылка на выходной файл и параметры записаны в `40-output-manifest.md`.

## Ограничения

- Не клади MP4 в Git.
- Не запускай FFmpeg, если входные файлы, права или монтажный лист не определены.
- Ошибка команды — это блокер с логом ошибки и следующим ручным шагом, а не повод
  придумывать несуществующий готовый рилс.
- Плагин `ffmpeg-llm` необязателен: если он доступен в конкретном чате, он лишь
  помогает сформулировать команду; проверку и экспорт выполняет FFmpeg.
