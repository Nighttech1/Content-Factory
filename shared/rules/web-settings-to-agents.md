# web-settings-to-agents.md — куда переехали веб-настройки

> Решение владельца (2026-11): веб больше ничего не настраивает — всё задаётся
> через агентов в облачных чатах Claude. Раздел «Настройки» убран из веба.
> Ниже — какая бывшая веб-настройка теперь у какого агента.

| Бывшая веб-настройка | Теперь владеет (агент) | Где лежит |
|---|---|---|
| **Дизайн / DESIGN.md / Quick Theme / библиотека дизайнов** | 🎨 `art-director` + `designer` | `projects/vernatun/brand/design.md` + скилл `shared/skills/brand-kit`. Разметку слайдов придумывает Дизайнер. |
| **Бренд: имя, тон, бриф** | 🎯 `content-director` (тон/бриф) | `projects/vernatun/brand/brief.md` |
| **Логотип** | 🎨 `designer` / `art-director` | Ставится **на HTML-слое** композита (поверх фона), НЕ в фон-картинку. Правило — `shared/pipelines/carousel/` (layered-html). Да, агент ставит логотип точно на HTML-слое. |
| **Персонажи (landscapes/cut-out)** | 🎨 `art-director` + `designer` | cut-out персонажи поверх фона; `brand/` + brand-kit. |
| **Площадки публикации** | 📤 Публикатор (Фаза P) + 🎯 `content-director` | куда/когда — в контент-плане; токены площадок — секреты окружения (`env.manifest.md`). |
| **Расписание (autofill)** | 🎯 `content-director` | он составляет расписание и пушит готовое в веб (`shared/rules/approve-loop.md`). |
| **Разведка (Scout: фильтры виральности, частота)** | 🔍 `scout` | `shared/skills/scout-apify` + память `memory/scout.md`. |
| **Модели LLM / температуры** | задаются в облачных сессиях агентов (подписка Claude Code) | не в вебе. |
| **Сколько блоков показывать в разделе (page-size)** | **ОСТАЁТСЯ в вебе** (единственная веб-настройка) | мелкий контроль отображения ленты; не про контент. |

## Как теперь настраивать (владельцу)
- Открываешь облачный чат с нужным агентом (Директор/Арт-директор/Дизайнер/Разведчик) и говоришь, что поменять (тон, дизайн, логотип, персонажей, частоту разведки, расписание).
- Агент правит свой бриф/память/скилл и присылает результат в веб. Веб — только просмотр результатов.
- Единственное, что крутится в самом вебе — сколько карточек показывать в разделе.
