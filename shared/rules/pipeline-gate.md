# pipeline-gate.md — эстафета задания и гейт публикации (общее правило)

> Общее правило для обоих проектов. Как задание проходит от плана до публикации и где стоят гейты.

## Поток
```
Контент-директор: план + папка отдела `jobs/<ID>/` + `00-brief.md`
   → владелец вручную передаёт ID нужному чату
   → Сценарист / лид отдела (по формату)
   → [Арт-директор / Видео-продюсер — визуал/сборка, на своих фазах]
   → drafts/ (черновик)
   → 🧐 Редактор (гейт качества: ✅/❌ + правки)
   → 👤 Человек (явный апрув)
   → 📤 Публикатор (в самом конце; пока владелец публикует вручную)
```

## Жёсткие гейты
1. **Редактор** — ни один материал не идёт дальше без вердикта `✅`. ❌ → возврат Сценаристу с правками.
2. **Человек** — после ✅ Редактора нужен **явный апрув человека**. Без него — никуда (ни в соцсети, ни на сайт).
3. Пока нет авто-Публикатора (Фаза P), после апрува **владелец публикует вручную** (IG/YouTube/TikTok), статьи — на сайт вручную.

## Где что лежит
- Плановые задания — `projects/<проект>/content-plan/ГГГГ-ММ.md` (новый ID вида `V-ГГГГММ-<КОД>-NN`).
- Производственная эстафета — `projects/<проект>/departments/<отдел>/jobs/<ID>/`.
- Текстовые черновики — при необходимости `projects/<проект>/drafts/`.
- Вердикты Редактора — в рабочей папке отдела по его шаблону.
- Тяжёлое медиа — во внешнее хранилище, в репо только ссылки/манифесты.

## Кто за какой формат (Сценаристы)

|---|---|

| Статья | `scriptwriter-article` |
| YouTube (длинное) | `scriptwriter-youtube` |
