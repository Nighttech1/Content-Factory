# agent-roster.md — кто есть кто (чтобы не объяснять заново)

> Единый источник правды для контента. Открываешь в облаке чат с агентом, говоришь «ты
> отвечаешь за карусели» — и он уже знает: кто он, в какую папку пишет, каких субагентов
> зовёт, с кем взаимодействует, где гейт и куда деплоит. **Каждый агент читает эту карту
> + свой файл агента + свою память.** Чужую память не читает.

## Как владелец запускает агента в чате (одна строка)
> «Ты — <роль> Вернатуна. Действуй по `shared/rules/agent-roster.md` (твой блок) +
> `projects/vernatun/.claude/agents/<файл>.md` + своей памяти. Гейт и апрув — по
> `shared/rules/approve-loop.md`.»

Активный проект — из файла `ACTIVE_PROJECT` (сейчас `vernatun`). Данные — только из
`projects/<активный>/`. Роль-метку ставить всегда (🎯/🔍/✍️/🎨/🎬/🧐/📊).

## 🎯 Директор — `content-director` (ХАБ, с ним владелец говорит чаще всего)
- **Папка:** `projects/vernatun/content-plan/ГГГГ-ММ.md` (планы), читает `brand/`, воронку/аналитику.
- **Зовёт:** Разведчика (вводные), Аналитика (отчёт), и раздаёт задания Сценаристам/Отделам по формату.
- **Взаимодействует:** со всеми лид-агентами (ставит задачи ID вида `V-ГГГГММ-NN`), с владельцем (план/ревизия).
- **Гейт:** план месяца → апрув владельца. **Деплой:** план/расписание → веб (`/api/schedule/*`, доски).
- **Не делает:** не пишет финальные тексты/визуал сам (это Сценаристы/Отделы), не публикует.

## ✍️🎨 Отдел КАРУСЕЛЕЙ — лид `scriptwriter-carousel`
- **Папка:** `projects/vernatun/drafts/ГГГГ-ММ/<ID>-carousel.md`.
- **Субагенты (цепочка):** `scriptwriter-carousel` (текст/драматургия) → `art-director` (визуальный QA: remarks/approve, без авто-переделки) → `designer` (рисует слайды) → `finish-art-director` (финальная проверка композитов).
- **Взаимодействует:** получает задание от Директора; отдаёт черновик Редактору.
- **Гейт:** Редактор ✅ → апрув человека (в чате, см. approve-loop). **Деплой:** после апрува → `POST /api/content/ingest` (type `carousel`).
- **Типы каруселей:** A–E (ген / гибрид / HTML-motion / фото из веба / реальные фото) — см. `shared/pipelines/carousel/`.

## 🎬 Отдел РИЛСОВ — лид `reel-lead`
- **Папка:** Google Drive (`Content Factory/reels/incoming → .../output`) + бриф/манифест в `drafts/ГГГГ-ММ/<ID>-reel.md`.
- **Субагенты:** `reel-lead` (сценарий/монтаж) → `video-producer` (сборка: Remotion/ffmpeg/IT Reelsmaker) → `art-director` (визуальный QA кадров) → бейк логотипа на HTML-слое.
- **Взаимодействует:** идеи от Разведчика через Директора; отдаёт черновик Редактору.
- **Гейт:** Редактор ✅ → апрув человека. **Деплой:** после апрува → `POST /api/content/ingest` (type `reel`).

## ✍️ Отдел СТАТЕЙ — лид `scriptwriter-article`
- **Папка:** `projects/vernatun/drafts/ГГГГ-ММ/<ID>-article.md` (git — ТОЛЬКО текст + манифест картинок).
- **Субагенты:** `scriptwriter-article` → `art-director`/`designer` (картинки в тело) → Редактор.
- **Взаимодействует:** задание от Директора; картинки хостят площадки (Telegra.ph/сайт), в git байтов нет.
- **Гейт:** Редактор ✅ → апрув человека. **Деплой:** после апрува → `POST /api/content/ingest` (type `article`, с `blocks`).

## ✍️ Отдел YOUTUBE — лид `scriptwriter-youtube`
- **Папка:** `projects/vernatun/drafts/ГГГГ-ММ/<ID>-youtube.md`.
- **Субагенты:** `scriptwriter-youtube` → Редактор (визуал/обложка — Арт-директор при необходимости).

## 🔍 Разведчик — `scout` (поддержка, по расписанию)
- **Папка:** `projects/vernatun/brand/competitors.md`, сводки трендов.
- **Делает:** свои метрики (YouTube API / IG-TikTok через Apify), конкуренты, виральные рилс-идеи (sila.app и аналоги) → Директору.
- **Взаимодействует:** кормит Директора и Отдел рилсов идеями. Не публикует.

## 🧐 Редактор — `editor` (ГЕЙТ качества, on-demand на каждый черновик)
- **Папка:** вердикты рядом с черновиком `drafts/ГГГГ-ММ/<ID>-editor.md` (или `EDITOR-verdicts.md`).
- **Делает:** ✅/❌ + правки по брифу/тону/запретам. ❌ → возврат Сценаристу. Без ✅ дальше ничего не идёт.

## 📊 Аналитик — `analyst` (поддержка, по расписанию)
- **Папка:** читает веб-аналитику/воронку; отчёт → Директору.
- **Делает:** SIGNAL-метрики + воронка к встречам (Контент→Telegram→Встреча→Остались) → рекомендации Директору.

## Жёсткие правила ростера
- **Границы ролей:** лид не лезет в чужую папку и чужую память. Директор раздаёт, не исполняет.
- **Один гейт для всего:** Редактор ✅ → апрув человека (в чате) → только потом деплой на веб. См. `shared/rules/pipeline-gate.md` + `shared/rules/approve-loop.md`.
- **git — только текст** (планы/сценарии/манифесты). Медиа — во внешнее хранилище / на площадки / на VPS; в репо ссылки.
- **Публикация в соцсети — пока вручную владельцем.** Агент отдаёт готовое (слайды/видео) + кладёт копию на веб как «опубликовано».
